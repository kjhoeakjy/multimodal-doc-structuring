# 구현 후보(1장 미포함, 면접 참고용)

작성 2026-10-28. 폐쇄망에서 독립 실행 가능한 공개 모델과 도구. 구상안 본문에는 모델명을 쓰지 않음.

| 단계 | 후보 | 공개 |
|---|---|---|
| 문서 파싱, 요소 위치 | Docling, Granite-Docling-258M | 2025-09, Apache 2.0 |
| 요소 위치 비교 후보 | Nemotron 3.5 Parse | 2026-10, OpenMDW 1.1 |
| 스키마 추출, 출처 기록 | Docling Graph | MIT |
| 질의응답 소형 LLM | Granite 4.1 3B, Ministral 3 8B | 2026-04, 2025-12, Apache 2.0 |

중국계 모델(MinerU, PaddleOCR-VL 등)은 문서 파싱 성능 상위권이나 후보에서 제외함. 추출물을 원본 영역에 다시 그려 대조하는 방식(RaV-IDP, 2026)은 보조 검증 수단으로 면접 답변에 활용함.

## 비교군 후보(2026-10-28 추가)

| 측면 | 구분 | 후보 | 비고 |
|---|---|---|---|
| 전처리 효율 | 기준선 | Tesseract 전체 페이지 OCR, Docling 기본 파이프라인(레이아웃 모델과 TableFormer) | 통용 방식 |
| 전처리 효율 | 최신 | Granite-Docling-258M 전체 페이지 변환, Nemotron Parse 전체 페이지 변환 | 문서 파싱 벤치마크(ParseBench) 상위권 공개 모델 중 도입 가능한 것 |
| 구조화 효과 | 기준선 | 고정 길이 분할, Docling 마크다운 뒤 요소 단위 분할(HybridChunker), 페이지 전체 입력 | 검색 증강 생성에서 통용 |
| 구조화 효과 | 최신 | 페이지 이미지를 소형 VLM에 직접 입력(Granite Vision 3.3 2B, Pixtral 12B), 시각 문서 검색(ColPali), 요소 그래프(Docling Graph) | 전처리 없이 이미지로 답하는 방식과 그래프 구축 방식 |

제외: MinerU, PaddleOCR-VL, dots.ocr, olmOCR 2(Qwen 계열 기반), InternVL 계열.
