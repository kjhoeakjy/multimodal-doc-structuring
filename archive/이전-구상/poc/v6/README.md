# PoC v6 제조 문서 풀 검증

구상안 v10의 처리 흐름(전체 기본 추출, 관계 점검, 선택적 추가 분석, 조건 연결 구조화)을 항공우주 제조 분야의 실제 공개 문서에 적용함. 실행 환경은 GPU 없는 노트북(CPU 16스레드, RAM 31GB).

## 데이터 풀

| 풀 | 문서 | 원본 | 형태 |
|---|---|---|---|
| 1 정비·수리 지침 | FAA AC 43.13-1B 7장 표 7-1 권장 토크 값 | faa.gov 공개 PDF | 디지털 원본, 같은 쪽의 스캔 변형(기울기 0.4도, 흐림, 잡음, JPEG 압축) |
| 2 엔지니어링 도면 | NIST 제품 제조 정보 시험 도면 FTC 6~11 1쪽의 일반 주기 | nist.gov 공개 PDF | 디지털 원본. 기하공차 기호는 벡터 도형 |
| 3 정비 계획 문서 | 구역 위치도, 구역별 점검 주기 표, 운용 환경 각주 | 합성(`poc/v5`) | 디지털 12건, 스캔 12건 |

원본 PDF는 `data/raw/`에 내려받아 사용하며 저장소에는 포함하지 않음.

## 파일

| 파일 | 내용 |
|---|---|
| `faa.py` | 풀 1 추출과 구조화. 표 테두리선 기준 열 구분, 다단 머리글 연결, 계열 구분 줄, 주의문과 각주 조건 연결, 스캔 기울기 보정, OCR 혼동 보정, 각주와 값 형식 누락의 영역 재해석 |
| `nist.py` | 풀 2 일반 주기 구조화. 공차 값과 데이텀은 있으나 기호가 없는 주기를 연결 누락으로 판단하고 PDF 벡터 객체로 기호 판별 |
| `run_faa.py`, `run_nist.py` | 비교 실행. 방식별 전처리 시간, 질의응답 정답률, 질의당 입력 토큰 수 기록 |
| `questions_faa.json`, `questions_nist.json` | 원본을 직접 확인해 작성한 질문과 정답 |
| `chain.sh` | 순차 실행 스크립트 |

## 비교 방식

| 기호 | 방식 | 구분 |
|---|---|---|
| A | 텍스트 레이어 또는 OCR, 고정 길이 분할, BM25 검색 | 기준선 |
| S | Docling 기본 파이프라인(레이아웃, 표 구조, OCR) 마크다운, BM25 검색 | 기준선(표준 도구) |
| B | Granite-Docling 258M 페이지 전체 변환, BM25 검색 | 최신 방식(전체 페이지 문서 VLM) |
| E | 페이지 이미지와 질문을 Granite Vision 3.3 2B에 직접 입력 | 최신 방식(종단형) |
| C | 제안. 조건이 연결된 항목에서 질문 조건에 맞는 값과 출처로 입력 구성 | 제안 |

답변 생성은 모든 방식이 같은 로컬 LLM(Granite 4.1 3B, CPU)을 사용함. 정답 판정은 정답 수치와 핵심어 포함 여부로 함.

## 중간 결과

| 항목 | 결과 |
|---|---|
| 풀 1 디지털 추출 | 값 100개 전부 추출, 나사 계열, 너트 종류, 하중 조건, 주의문, 추정값 각주 연결. 0.2초, GPU 미사용 |
| 풀 1 관계 점검 | 디지털에서도 열 수 불일치(5열 중 4열)를 누락으로 탐지해 표 범위 결정 방식 수정 |
| 풀 1 스캔 | 기울기 보정 전 6/100, 보정과 OCR 혼동 규칙 적용 후 99/100. 각주 누락은 표 하단 영역 재해석으로 복구(22초) |
| 풀 1 전처리 시간(1쪽) | 제안 0.2초, Docling 기본 19초, Granite-Docling 전체 페이지 120초 |
| 풀 2 | 6개 도면 중 4개에서 기호 누락을 탐지하고 벡터 객체로 면의 윤곽도 판별. VLM과 GPU 미사용 |
| 풀 3 | 스캔본 각주 재해석에서 소형 VLM이 문서에 없는 문장 생성. VLM 출력을 1차 OCR 문장과 대조해 유사도가 낮으면 기각하도록 수정 |

질의응답 비교 결과는 실행 완료 후 기재함.

## 확인된 한계

- 소형 VLM은 작은 영역에서도 CPU 기준 6~60초가 걸리며 입력 크기와 생성 길이 상한이 없으면 반복 생성이 발생함
- 소형 VLM은 각주 기호(*)를 보존하지 못하고 문서에 없는 문장을 생성하는 경우가 있어 출력 검증이 필요함
- 풀 2의 기호 판별은 곡선과 밑변 유무를 보는 단순 규칙이며 면의 윤곽도 계열에 한정됨
- 풀 1의 열 구분과 머리글 연결은 테두리선이 있는 표를 전제로 함
