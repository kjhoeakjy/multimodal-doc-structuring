# PoC v4 체결 토크 사례 (2026-10-28, 1차 실행)

구상안 v10의 처리 흐름을 합성 정비 문서로 실행하고 고정 길이 분할 방식과 비교함.

## 합성 문서

- 20건(디지털 10, 스캔본 10). 문서 1건 = 범위 조항 + 그림 1 조립도(부품 상자 4개, 원 안 번호 체결부 8개) + 표 1 체결부 토크(항목, 규격, 토크) + 각주(윤활 시 규격별 값) + 주기.
- 체결부와 부품의 소속은 그림에 있고 토크 값은 표에 있고 윤활 조건 값은 각주에 있어 세 형식에 분산됨.
- 스캔본은 130dpi 렌더 후 잡음, 흐림, JPEG 압축. 텍스트 레이어 없음.
- 생성: `python3 gen.py data`. 실행: `python3 pipeline.py data`. 생성 데이터는 커밋하지 않음.

## 실험군

| 실험군 | 전처리 | 입력 구성 |
|---|---|---|
| A 고정 분할 | pdftotext 또는 전체 페이지 300dpi OCR | 300토큰 청크, BM25 상위 3개 |
| B 평문 분할 | 제안과 같은 추출과 재처리 결과를 평문으로 펼침 | 300토큰 청크, BM25 상위 3개 |
| D 요소 단위 분할 | 제안과 같은 추출 결과를 문단, 그림 캡션과 라벨, 표(마크다운)와 각주의 요소 단위로 분할 | BM25 상위 2개 요소 |
| E 페이지 전체 입력 | D와 같은 요소 전부 | 검색 없이 페이지 전체 |
| C 제안 | 전체 기본 추출(디지털 파서 또는 130dpi OCR과 도형 검출), 관계 점검, 문제 영역 300dpi 재처리, 구조화 | 질문의 대상과 조건에 맞는 관계 |

D는 레이아웃 파서 뒤 마크다운으로 변환해 요소 단위로 분할하는 통용 방식에 해당하며 E는 텍스트 기반 방식의 상한에 해당함. 둘 다 추출 품질은 C와 같게 두어 구조화 방식의 차이를 분리함.

관계 점검 기준: 그림의 체결부 수와 표의 행 수 불일치, 각주는 있는데 기호가 붙은 셀 없음, 체결부 번호 판독 실패 또는 중복.

컨테이너에는 VLM과 LLM이 없음. 추가 분석은 고해상도 영역 OCR로 대신하고 답변 판독은 규칙으로 함. A와 B의 수치는 입력에 정답 도출에 필요한 정보가 모두 있는 비율(근거 완전성).

- 디지털: A 84%, B 84%, D 84%, E 84%, C 100%. 스캔본: A 0%, B 63%, D 69%, E 69%, C 84%.
- 값과 조건 조회는 표와 각주를 한 요소로 묶는 D에서 B보다 올라감. 그림 연결과 조건 미지정 조회는 E처럼 페이지 전체를 입력해도 0%이며 소속 관계가 텍스트에 없고 그림의 위치 관계에 있기 때문임.
- 합성 문서는 한 페이지가 240토큰 정도라 E의 토큰 부담이 실제 교범보다 작게 나타남.
- C의 오답 29건 = 보류 24건(필요한 값이 미확정이라 전달하지 않음) + 오답 5건(규격 셀 미판독으로 윤활 값 없이 전달 4건, 48을 43으로 오판독 1건).
- 스캔본 문서당 추가 분석 영역 평균 5.6개(체결부 번호 36회, 표 10회), 미해결 연결 평균 1.5건.
- 처리 시간(CPU): 스캔본 문서당 A 1.6초, C 기본 추출 2.9초 + 관계 점검과 재처리 4.4초. OCR 기준 재처리는 전체 페이지 고해상도 OCR보다 길었음.

## 확인된 한계와 반영

| 발견 | 반영 |
|---|---|
| 기본 해상도 OCR은 격자 표의 행과 원 안의 번호 1, 7을 자주 놓침 | 관계 점검 기준에 행 수와 체결부 수 불일치, 번호 판독 실패와 중복을 추가. 문제 영역에 한정해 고해상도 재처리 |
| 전체 페이지 OCR(psm 6)은 격자 표를 거의 읽지 못함 | 표 영역은 선 검출 후 셀 단위 OCR. 셀 높이 정규화와 이진화 필요 |
| 각주 기호 *는 작아서 셀에서 자주 누락 | 각주가 규격을 명시하므로 규격 기준으로 연결. 기호는 보조 근거 |
| OCR이 AI-330을 Al-330으로 읽음 | 식별자 정규화(l을 I로) 뒤 대조 |
| 원 안의 숫자는 이진화와 여백 없이는 판독률이 낮음 | 영역 재처리 시 이진화, 여백 추가, 단일 문자 모드 |
| 숫자 오판독(48을 43)은 관계 점검으로 발견되지 않음 | 원본 표본 대조와 중요 값 별도 확인 필요. 구상안 한계로 명시 |
| OCR 재처리는 비용이 줄지 않음 | 절감 조건을 VLM 기준으로 한정. 노트북에서 VLM 처리 시간 측정 |

## 재구성 검증 실험(v12, 2026-10-29)

오류 유형별 규칙 대신 "판독 결과를 다시 그려 원본과 비교"하는 유형 무관 점검이 누락과 오판독을 얼마나 찾는지 스캔본 10건으로 측정함. 실행: `python3 recon_check.py data <디지털 재생성본 경로>`. 정답 위치는 같은 문서의 디지털 재생성본(`gen.py`에서 스캔 변환을 뺀 것)의 단어 좌표를 130dpi로 환산해 얻음.

| 구성 | 내용 |
|---|---|
| 1차 판독(수준 1) | 130dpi 렌더, 페이지 OCR(단어 상자), 격자 셀 OCR(셀 상자), 긴 선과 원 검출 |
| 재구성 | 판독 글자를 같은 상자에 같은 크기로 다시 그리고 검출 도형을 그림 |
| 오차 1 미설명 잉크 | 원본 잉크에서 재구성 요소가 덮는 영역을 지운 뒤 남는 연결 성분(잉크 25픽셀 이상) |
| 오차 2 글자 불일치 | 판독 단어마다 재구성 글자와 원본 잉크의 Dice 유사도. 정상 단어 하위 10%를 경보로 허용하는 임계값 |
| 오차 2 보조 | 같은 절차를 300dpi로 수행한 2차 판독과 문자열 유사도 0.75 미만이면 불일치 |
| 정답 | 디지털 재생성본 단어와 대응(상자 겹침). 대응 없음은 누락, 대응은 있으나 글자가 다르면 오판독. 분절 차이는 포함 관계로 허용 |

결과(스캔본 10건, 정답 단어 1,292개)

| 항목 | 결과 |
|---|---|
| 누락 131건 | 미설명 잉크 영역에 덮인 것 127건(97%). 본문 줄 120/120, 표 셀 7/11 |
| 미설명 영역 | 문서당 4.4개. 영역 44개 중 실제 누락을 포함한 것 34개(정밀도 77%) |
| 오판독 166건 | 2차 판독 불일치 107건(64%, 정상 단어 오경보 7%). 글자 Dice 110건(66%, 오경보 10%). 둘의 합집합 140건(84%, 오경보 16%) |
| 오판독 유형별(합집합) | 그림 라벨 40/40, 체결부 번호 74/78, 본문 10/20, 표 셀 13/22, 각주 3/6 |
| 전체 오류 297건 | 어느 한 신호로 표시된 것 267건(90%) |
| 표시 단위 | 문서당 미설명 영역 4.4개와 불일치 단어 30개. 단어는 인접 단위로 묶으면 영역 수가 줄어듦 |

확인된 점

- 누락은 오류 유형을 정의하지 않아도 미설명 잉크로 거의 전부 잡힘. v10과 v11의 규칙(행 수, 각주 기호, 번호 판독 실패)이 겨냥한 누락이 모두 포함됨
- 오판독은 글자 모양 대조보다 2차 판독 불일치가 오경보가 적음. 본문과 각주의 오판독(N·m을 Nem으로)은 두 신호 모두 약함. 표 셀의 수치 오판독은 22건 중 13건 탐지
- 2차 판독의 비용은 1차의 약 3배(300dpi). 예산 안에서 의심 영역에 한해 수준을 올리는 구조에서 1차 판독이 전체 비용을 정함
- 합성 문서 기준. 실제 문서(FAA 표, NIST 도면)에서의 채택 수준 분포와 GPU 시간은 노트북에서 측정 예정
