# 기술 문서의 관계 그래프 직렬화가 소형 텍스트 언어 모델의 질의응답 정답률에 미치는 효과 (초고)

작성일 2026-10-30. 수치는 실험 4차(`examples/llm-qa/results/api-small-2026-10-v4`) 기준. 국문 초고이며 투고 형식에 맞춘 축약은 이후 작업.

## 초록

폐쇄망·제한 GPU 환경에서는 표·도면·그림이 섞인 기술 문서를 생성형 시각 언어 모델 없이 텍스트 언어 모델에 입력해야 함. 통상의 방법은 문자 인식 결과를 읽는 순서로 이어 붙이는 것이나 이 방식은 요소 간 연결·포함·지시 관계를 잃음. 본 연구는 문서를 시각 요소(도형·문자·기호·표·문단)의 노드와 연결·포함·지시의 간선으로 이루어진 관계 그래프로 변환하고 이를 원본 좌표가 붙은 텍스트로 직렬화해 텍스트 언어 모델에 전달하는 방법을 제안함. 공개 자료 15건에서 정답이 확정된 240문항을 만들고 문자 인식 텍스트(ocr), 전체 직렬화(full), 질의 부분 그래프(retrieved)의 세 입력 조건으로 소형 상용 API 모델의 정답률을 비교함. 전체 정답률은 39.2%, 58.8%, 57.9%였고(95% 부트스트랩 구간 각각 [32.9, 45.4], [52.5, 64.6], [51.7, 63.7]), 벡터 P&ID에서는 16%에서 88%로, 관계 질문(연결·개수·노즐·라인·계기)에서는 0~23%에서 43~67%로 올랐음. 표·본문 중심 자료에서는 문자 인식 텍스트로 70~100%에 이르러 구조화의 이득이 없었고 표 질문은 직렬화가 오히려 낮았음. 래스터 P&ID는 요소 추출 품질이 정답률의 상한이며 추출 개선으로 스캔본 정답률이 16%에서 37%로 올랐음. 부분 그래프 조건은 전체 직렬화 대비 입력 길이 28%로 정답률 차이 1%p 안에 들었음. 같은 문항 80개에서 CPU로 실행한 8B급 공개 가중치 모델은 36%, 62%, 64%로 상용 소형 모델(36%, 57%, 61%)과 같은 크기의 효과를 보여, 결과가 특정 모델에 매이지 않음을 확인함. 질문 종류에 따라 관계 질문에는 그래프, 읽기 질문에는 문자 인식 텍스트를 고르면 같은 응답에서 64~65%가 됨(사후 규칙).

## 1. 서론

항공·플랜트 분야의 기술 문서는 배관 계장도(P&ID), 기계 도면, 표와 그림이 섞인 정비 매뉴얼로 이루어지며 핵심 정보가 요소 사이의 관계(어느 장비가 어느 배관으로 이어지는가, 어느 치수가 어느 부품을 가리키는가, 어느 셀이 어느 머리글에 속하는가)에 있음. 이런 문서를 언어 모델로 질의하려면 그림을 모델이 읽을 수 있는 형태로 바꿔야 함.

시각 언어 모델은 그림을 직접 입력받으나 폐쇄망·제한 GPU·공개 가중치 모델이라는 운용 조건에서는 적용이 어렵고 관계 질의의 정확도도 보장되지 않음. 문자 인식 결과를 이어 붙여 검색 증강 생성(RAG)에 쓰는 방식은 운용이 쉬우나 관계 정보가 사라짐. 본 연구의 질문은 다음과 같음. 그림의 요소와 관계를 명시적으로 추출해 텍스트로 직렬화하면 같은 텍스트 모델의 관계 질의 정답률이 얼마나 오르는가, 그리고 어떤 종류의 문서·질문에서 이득이 없는가.

기여는 세 가지임. (1) 벡터·래스터 문서를 공통 관계 그래프로 바꾸는 처리 경로와 좌표·관계를 포함한 직렬화 형식. (2) 공개 자료와 확정 정답으로 구성한 240문항의 질의응답 평가 세트와 채점 규칙. (3) 세 입력 조건의 비교 실험과 자료·질문 종류별 분석.

## 2. 관련 연구

문서 레이아웃 분석과 표 구조 인식은 쪽 단위 요소(문단·표·그림)의 검출과 셀 구조 복원을 다루며 이 연구의 쪽 경로는 그 결과를 전제로 함. 벡터 그래픽의 언어 모델 이해에 관한 연구는 그림을 기하 기본 요소의 텍스트로 표현하면 텍스트 모델이 이를 추론할 수 있음을 보였으며 본 연구의 설계 원리가 됨. P&ID의 그래프 복원 연구는 기호 검출과 선 추적으로 연결 그래프를 만들고 DEXPI 형식의 정답과 비교함. 본 연구는 이들을 결합해 그래프를 텍스트 모델의 입력으로 직렬화하고 그 효과를 질의응답 정답률로 측정하는 점이 다름. 문헌 정독 요약은 `archive/이전-구상/research/논문-정독-노트.md`에 있음.

## 3. 방법

### 3.1 처리 경로

입력을 판별해 다섯 경로 중 하나로 처리함. 판별은 문자 밀도, 선·도형 밀도, 장비·계기 태그 유무, 치수 문자 유무로 함.

| 경로 | 입력 | 요소 추출 |
|---|---|---|
| 벡터 P&ID | SVG, 벡터 PDF | 기본 요소(선·원·경로) 파싱, 문자 좌표 그대로 사용 |
| 래스터 P&ID | 스캔·렌더 이미지 | 기울기 보정, 문자 인식, 축 평행 선 검출, 닫힌 도형·기호 검출 |
| 쪽(표·본문) | 보고서·매뉴얼 쪽 | 문자 인식 또는 PDF 글자 층, 괘선·문자열 기반 표 복원, 단 분리, 문단·제목·캡션 |
| 기계 도면(도해) | 벡터·래스터 도면 | 투상도 영역, 치수·주기·기준 문자, 지시선, 표제란 |
| 사진 | 현장 사진 | 문자 인식 결과와 임베딩 색인 |

### 3.2 관계 그래프

노드는 도형(장비·탱크·펌프), 기호(밸브·계기·끝막음), 문자, 표, 문단, 그림 영역, 투상도 영역임. 간선은 연결(선과 접점으로 확인한 배관·신호), 포함(표 안의 셀, 그림 안의 문자), 지시(지시선이 가리키는 부품, 주석이 설명하는 요소)임. P&ID에서는 축 평행 선을 접점에서 이어 선 구간(run)을 만들고 기호가 선 위에 놓이면 구간을 자르며 분기점을 노드로 둠. 문자는 거리와 방향으로 가장 가까운 요소나 선 구간에 귀속하고, 장비 태그 형식의 문자는 태그가 없는 가장 가까운 장비에 30 mm 안에서 귀속함. 노즐은 소속 장비로 올리고 접속구 번호와 바로 뒤 호칭 지름을 쌍으로 묶음.

### 3.3 직렬화

그래프를 좌표가 붙은 텍스트 줄로 씀. 항목은 요소(식별자·종류·이름·라벨·접속구·좌표), 분기점, 연결(종류·양 끝·흐름 방향·라벨의 라인 번호·유체·등급·호칭 지름·경로 좌표), 장비 간 배관 연결(밸브·분기점은 지나고 다른 장비는 지나지 않은 도달 집합), 표(머리글=값 형식의 행), 요소에 붙지 않은 문자임. 장비 간 도달은 구조화 단계에서 미리 계산해 넣는데, 소형 모델이 연결 줄을 여러 단계 따라가지 못하는 문제를 보완하기 위함임. 모든 줄에 원본 좌표를 남겨 답의 근거 영역을 되짚을 수 있게 함.

### 3.4 질의 부분 그래프

질문에 든 태그를 기준으로 연결 간선을 2단계 따라간 부분 그래프에 질문어와 겹치는 줄 상위 18개와 표 머리글 행을 더해 짧은 문맥을 만듦. 긴 직렬화 전체를 넣기 어려운 작은 문맥 창의 모델을 위한 조건임.

## 4. 실험 설계

### 4.1 자료와 문항

| 자료 | 문항 | 정답 출처 |
|---|---|---|
| DEXPI C01 P&ID: 벡터, 200 dpi 래스터, 스캔 열화 | 43 × 3 | DEXPI XML(연결·노즐 수·노즐 호칭 지름·라인 속성·계기 기능 문자) |
| DEXPI C02·C03 P&ID 벡터 | 12 | DEXPI XML |
| 합성 보고서(영문 PDF 글자 층·150 dpi 스캔), 한글 보고서, 한글 표·본문 스캔 | 35 | 생성 스크립트의 값 |
| 합성 기계 도면(벡터·래스터) | 20 | 생성 스크립트의 값 |
| FAA AC 43.13-1B 토크 표(원본·스캔), 볼트 표, 본문 2단 쪽 | 44 | 원문 대조 값 |

질문 종류는 연결·개수·노즐·라인·계기(관계 질의)와 표·본문·치수·그림·주석(읽기 질의)임. 연결 질문의 정답은 XML 연결 정보에서 이름 없는 부품을 지나 탐색한 장비 태그 집합임. DEXPI 플랜트·실험실 도면은 그림과 XML에 문자 라벨이 없어 제외함.

### 4.2 조건과 채점

세 조건 모두 같은 지시문("주어진 자료만 근거로 답하고 값·태그·짧은 구만 쓴다, 근거가 없으면 '자료에 없음'")과 같은 모델을 씀. 채점은 근거 없음 취지의 응답('자료에 없음', '확인되지 않음' 등)을 정답 숫자가 섞여 있어도 오답으로 보고, 숫자 답은 자릿수 경계가 맞는 숫자 토큰만 인정하며(80과 800 구분), 문자 답은 낱말 경계 안의 포함(영문 복수형 허용), 집합 답은 응답에서 뽑은 태그 집합과 정답 집합의 완전 일치로 하되 질문에 든 기준 태그는 제외함. 초기의 단순 포함 규칙은 20건을 과대 채점했으며(4차 full 62.5%), 본문 수치는 모두 엄격 규칙으로 다시 채점한 값임. 모델은 상용 API의 소형 모델(결과 이름 `api-small-2026-10`, 240문항 전체)과 8B급 공개 가중치 지시 모델(결과 이름 `open-8b-2026-10-s80`)임. 공개 가중치 모델은 폐쇄망 조건을 흉내 내어 GPU 가속 없는 노트북 CPU(16코어)에서 로컬 실행했고, 호출당 30~110초가 걸려 자료 묶음×질문 종류 비율을 유지한 층화 80문항(`subset-80.json`)으로 줄였으며 상용 모델의 값도 같은 80문항에서 다시 계산해 비교함.

두 모델의 조건별 정답률이 0~5%p 안에서 같고, 질문 종류별 모양(연결 0%에서 50~83%, 노즐 10%에서 65~75%, 표는 ocr이 같거나 높음)도 같음. 응답 시간은 로컬 실행기의 프롬프트 캐시 순서 효과가 있어 조건 간 비교에 쓰지 않음.

### 5.5 직렬화·추출 개선의 누적 효과

같은 모델·문항에서 직렬화와 추출을 바꾼 네 차례 실행의 full 정답률은 48%, 52%, 54%, 59%였음. 2차는 배관 라벨의 항목 분해(라인·유체·등급·DN)와 접속구 호칭 지름 추가, 3차는 장비 간 도달 집합 추가, 4차는 장비 태그 귀속·요소에 붙지 않은 문자·표 머리글=값 형식과 래스터 조각·눈금 병합·모서리 연결임. 연결 질문은 7%, 40%, 67%로 올랐고 래스터 스캔 P&ID는 16%에서 37%로 올랐음. 반면 4차의 표 머리글=값 형식은 FAA 토크 표의 full 정답률을 54%로 낮춤(ocr 89%).

### 5.6 질문 종류별 표현 선택(사후 규칙)

관계 질문(연결·개수·노즐·라인·계기)에는 그래프 조건의 응답, 읽기 질문(표·본문·치수·그림·주석)에는 문자 인식 텍스트 조건의 응답을 고르면 같은 240문항에서 64.2%(full)·65.0%(retrieved)가 됨(8B 모델 80문항에서 65.0%). 규칙을 결과를 본 뒤 정했으므로 상한에 가까운 추정이며 별도 평가 세트에서 다시 재야 함.

## 6. 분석

- 관계 질의에서의 효과. 벡터 P&ID에서 ocr 16%, full 88%(C02·C03 25%, 75%)로 차이가 가장 큼. 연결·개수·노즐·라인·계기 질문 모두 full이 ocr보다 21~67%p 높음. 효과의 원천은 모델이 아니라 구조화 단계에서 확정한 관계(접점으로 확인한 연결, 접속구와 호칭 지름의 쌍, 장비 간 도달, 장비 밖에 적힌 태그의 귀속)임.
- 읽기 질의에서의 역효과. 표·치수·그림 질문은 ocr이 높음(표 87% 대 68%, 치수 67% 대 42%). 좌표·관계 줄과 머리글 반복이 소형 모델의 주의를 분산해 FAA 토크 표에서 ocr 89%, full 54%임. 이는 직렬화가 질문 종류에 따라 선택되어야 함을 뜻함.
- 추출 품질의 상한. 래스터 P&ID의 full 정답률은 정답 인접 쌍 복원율과 함께 움직임. 조각·눈금 병합과 모서리 연결로 복원이 27개 중 12개에서 18개(200 dpi), 16개(스캔)로 오르자 정답률이 21%에서 33%, 16%에서 37%로 오름. 남은 오답은 태그 문자 인식 오류(H1008을 S8로 읽음)와 복원되지 않은 연결이며 오답 대부분이 '자료에 없음'(full 조건 61건 중 38건이 래스터 P&ID)임.
- 부분 그래프의 효율. retrieved는 입력 길이가 full의 28%이고 정답률 차이는 1%p(구간이 0을 포함)로, 작은 문맥 창의 모델에서는 부분 그래프가 실용적임.
- 모델 독립성. 공개 가중치 8B 모델을 CPU에서 돌린 결과가 상용 소형 모델과 같은 크기의 효과를 보임. 효과가 입력 텍스트의 구조에서 나오며 특정 모델의 능력에 기대지 않음을 뜻함.
- 모델의 한계. 3차에서 장비 간 도달을 미리 계산해 넣기 전에는 연결 정답률이 7%였음. 소형 모델은 연결 줄을 두 단계 이상 따라가지 못하므로 다단계 추론은 구조화 단계가 맡아야 함.

## 7. 한계

- 모델 2종(상용 소형 1종, 공개 가중치 8B 1종), 실행 1회씩이며 응답 온도 고정. 공개 가중치 모델은 80문항 부분집합이라 구간이 ±10%p로 넓고 7B·14B급은 실행하지 않음.
- 240문항은 서로 다른 질문 문장 121개의 반복이고 합성 자료 문항이 55건이며, 같은 문항으로 직렬화를 네 차례 고쳐 별도의 미사용 평가 세트가 없음. 신뢰구간 폭이 ±6~8%p임.
- 요소 추출은 작성 양식이 같은 DEXPI C01에서 가장 높고(연결 27/27), 양식이 다른 C02·C03(3/6, 4/9)과 복잡한 플랜트 도면(84/157)에서 떨어짐. 기계 도면·차트·사진의 의미 해석은 범위 밖임.
- 이미지 임베딩은 분류용 합성곱 신경망의 특징 벡터이며 자연어 질문과 정렬된 공통 임베딩이 아니고, 실험에 쓰지 않음.
- 표 직렬화 형식(머리글=값)이 표 질문의 정답률을 낮췄으며 행 단위 형식과의 비교 실행이 필요함.
- 래스터 P&ID의 요소 추출(조각 병합, 가로지르는 표시의 분할, 태그 인식 오류)이 정답률을 제한함.
- 세 조건 모두 질문이 속한 문서 1건의 자료를 넣는 실험이며, 여러 문서에서 조각을 찾아오는 검색(어휘·임베딩)은 측정하지 않음. retrieved 조건의 검색은 태그 기준 그래프 탐색과 질문어 겹침임.
- 공개 벤치마크가 없어 다른 방법과의 직접 비교가 없음.

## 8. 결론

시각 요소와 관계를 명시적으로 추출해 좌표가 붙은 텍스트로 직렬화하면 같은 소형 텍스트 모델의 관계 질의 정답률이 크게 오르며(전체 39.2%에서 58.8%, 벡터 P&ID 16%에서 88%), 래스터 도면은 추출 품질이 상한이어서 추출 개선이 그대로 정답률로 이어짐(스캔 16%에서 37%). 질문 종류에 따라 관계 질문에는 그래프, 읽기 질문에는 원본 텍스트를 고르는 선택이 다음 단계이며 사후 규칙으로 64~65%임. 표·본문 중심 문서는 문자 인식 텍스트로 충분하고 표 질문에는 직렬화가 오히려 해가 됨. 효과는 CPU에서 돌린 8B급 공개 가중치 모델에서도 같은 크기로 나타나 폐쇄망·제한 GPU 조건에서 쓸 수 있음. 다단계 관계 추론은 모델이 아니라 구조화 단계에서 미리 계산해 넣어야 함. 향후 과제는 래스터 추출 개선, 공개 가중치 모델 비교, 질문 종류에 따른 직렬화 선택임.
