# 연구 설계 v2: 추출 그래프의 정확도가 소형 언어 모델 질의응답에 미치는 영향

작성 2026-11-02. [v1](연구-설계-v1.md)의 질문별 표현 선택은 개발 세트에서 이득이 작아(+1.2%p, 순증 3문항) 본 주제에서 내리고, 추출 오류의 영향을 본 주제로 정함. 연결 검증 주제는 사전 판정(`examples/edge-verification/`)에서 신호가 약해(AUC 0.67) 분석 절로 옮김.

## 1. 연구 질문

가제: How Accurate Must Extracted Diagram Graphs Be? Error-Controlled Analysis of Graph-Based Question Answering with Small Language Models (추출 도면 그래프는 얼마나 정확해야 하는가: 소형 언어 모델 그래프 질의응답의 오류 통제 분석)

| 번호 | 질문 | 측정 |
|---|---|---|
| Q1 | 연결 누락, 거짓 연결, 라벨 오귀속은 각각 정답률을 얼마나 떨어뜨리는가 | 오류 비율별 정답률 곡선, 오류 종류 간 기울기 비교 |
| Q2 | 그래프 입력이 문자 인식 텍스트보다 나빠지는 추출 정확도(손익분기점)는 어디인가 | 곡선과 ocr 정답률의 교점(간선 재현율·정밀도·F1) |
| Q3 | 실제 추출기의 오류는 통제 오류와 같은 효과를 내는가 | 실제 래스터·스캔 추출 결과(실측 재현율·정밀도)가 곡선 위에 놓이는지 |
| Q4 | 질문 종류(연결, 개수, 노즐, 라인, 계기)와 모델 규모에 따라 민감도가 다른가 | 종류별 곡선, 모델 2~3종 비교 |

기여
1. 그래프 기반 기술 도면 질의응답에서 추출 오류 종류·비율과 정답률의 관계를 통제 실험으로 처음 정량화함
2. 그래프 입력이 텍스트 입력보다 나아지는 추출 정확도 기준과 오류 종류별 우선순위(어떤 오류부터 줄여야 하는가)를 제시함
3. 실제 추출 오류의 구성(분기점 분할, 요소 병합, 노드 대응 실패)을 분석하고 위상 정규화의 효과를 보임

## 2. 선행 연구와의 차이

| 연구 | 그래프 출처 | 추출 오류의 영향 |
|---|---|---|
| PIDQA(MAKE 2025) | 영상에서 인식한 그래프 | 다루지 않음(질의 언어 변환 정확도 중심) |
| ChatP&ID(AIChE J. 2026) | DEXPI XML(오류 없음) | 다루지 않음(추출 단계 없음) |
| PID2Graph(2025) | 영상에서 학습 기반 추출 | 추출 F1을 보고하나 하위 질의응답 영향은 다루지 않음 |
| 본 연구 | 정답 그래프 + 통제 오류, 실제 규칙 기반 추출 | 오류 종류·비율별 정답률, 손익분기점, 실제 오류와의 대조 |

## 3. 실험

### 3.1 테스트베드

| 테스트베드 | 정답 그래프 | 문항 | 용도 | 상태 |
|---|---|---|---|---|
| T1. DEXPI C01 | 벡터 추출 그래프(정답과 일치, 재현율·정밀도 1.00) | 기존 43문항(연결·개수·노즐·라인·계기) | 개발, 실제 추출(200 dpi, 스캔)과의 대조 | 코드 완료(`noise.py`, `run_noise.py`) |
| T2. PIDQA | Dataset-P&ID 주석(기호 상자·분류, 선)으로 만든 그래프 | PIDQA 질문(CC0) 중 연결·개수 유형 | 규모 확대 평가(도면 50장, 도면 단위로 개발과 분리) | 데이터 내려받기 필요(구글 드라이브) |
| T3. PID2Graph | graphml 정답 | 그래프에서 자동 생성한 연결 문항 | 실물 도면 일반화 | 데이터 내려받기 필요(9.3 GB) |

### 3.2 오류 종류와 수준

| 종류 | 방법 | 수준 |
|---|---|---|
| 연결 누락 | 배관·신호 간선 무작위 삭제 | 0, 10, 20, 30, 50% |
| 거짓 연결 | 가까운 요소 쌍(이웃 5개 안) 사이 간선 추가 | 간선 수의 0, 10, 20, 30, 50% |
| 라벨 오귀속 | 선 라벨(라인 번호·유체·등급·DN) 맞바꿈 | 0, 10, 20, 30, 50% |
| 분기점 분할(추가) | 간선 중간에 연결 둘인 분기점 삽입 | 실제 래스터 오류 유형 재현 |
| 요소 병합(추가) | 인접 요소 두 개를 한 노드로 합침 | 실제 오류 유형 재현 |

오류를 넣은 그래프마다 DEXPI XML(또는 주석)과 다시 대조해 실제 간선 재현율·정밀도를 기록하고, 곡선의 가로축은 넣은 비율이 아니라 실측값으로 함. 씨앗 3개.

### 3.3 입력 조건과 모델

- 입력: ocr(기준선), relations(요소+연결), full(+장비 간 도달). full의 도달 집합은 오류가 들어간 그래프에서 다시 계산함(전처리 오류가 도달 계산으로 전파되는 효과 포함)
- 모델: CPU 실행 8B 공개 가중치(주 결과), 상용 소형(규모 비교), 가능하면 7B·14B급 공개 가중치 1종
- 채점: 기존 정확 일치 규칙. 통계: 씨앗 평균과 문항 묶음 재표집 구간, 오류 수준 간 대응 비교

### 3.4 분석

- 실제 추출 오류 구성: 래스터 C01 틀린 연결 35개 중 24개가 연결 둘인 분기점을 지남. 분기점 축약 시 정밀도 0.35에서 0.56(`examples/edge-verification`)
- 연결 검증 신호의 한계: 끝점 간격 AUC 0.47, 위상 제약 0.64, 다중 추출 일치도 0.67. 틀린 연결도 실제 선을 따름
- 조건 분리 결과(objects, relations, full)는 오류 0% 기준점으로 씀
