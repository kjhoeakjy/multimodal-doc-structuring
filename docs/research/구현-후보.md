# 구현 후보(1장 미포함, 면접 참고용)

작성 2026-10-28. 폐쇄망에서 독립 실행 가능한 공개 모델과 도구. 구상안 본문에는 모델명을 쓰지 않음.

| 단계 | 후보 | 공개 |
|---|---|---|
| 문서 파싱, 요소 위치 | Docling, Granite-Docling-258M | 2025-09, Apache 2.0 |
| 요소 위치 비교 후보 | Nemotron 3.5 Parse | 2026-10, OpenMDW 1.1 |
