- 중국계 모델·도구(Qwen 계열 검색 모델, Qwen 아키텍처 기반 LightOnOCR-3, PaddleOCR 기반 도구, MinerU)는 구현 후보에서 제외. 연구 근거 인용은 허용.
- Nemotron 3.5 Parse는 OpenMDW 1.1 배포 조건 확인 후 비교 실험 후보로만 사용.
