## 3. 제외 원칙

- 중국계 모델·도구(Qwen 계열 검색·생성 모델, Qwen 아키텍처 기반 LightOnOCR-3, PaddleOCR 기반 도구, MinerU, GLM, InternVL)는 구현 후보에서 제외. 연구 근거 인용은 허용하되 표에 기반 모델을 명기.
- Nemotron 3.5 Parse는 OpenMDW 1.1 배포 조건 확인 후 비교 실험 후보로만 사용.
- 원문을 확인하지 못한 수치(Drawing-Checker)는 인용하지 않음.
