# 주요 학회 논문 근거

확인일 2026-10-28. 학회와 연도는 공식 페이지(ACL Anthology, CVF Open Access, ECVA, PMLR, NeurIPS·ICLR·MLSys 논문집, ACM DOI)에서 확인함. 프리프린트로 공개된 연구는 이 목록에서 제외하고 `출처-검증.md`에 보조 근거로 둠.

## 1. 문서 전처리

| 논문 | 학회 | 핵심 | 확인한 결과 | 활용 |
|---|---|---|---|---|
| [DocLayNet](https://doi.org/10.1145/3534678.3539043) | KDD 2022 | 금융, 특허, 매뉴얼 등 80,863쪽에 11개 레이아웃 클래스를 사람이 표기 | 학습 모델이 사람 간 일치도보다 약 10% 낮음 | 페이지를 표, 그림, 본문, 캡션 영역으로 나누는 1차 추출 |

| [PubTables-1M](https://openaccess.thecvf.com/content/CVPR2022/html/Smock_PubTables-1M_Towards_Comprehensive_Table_Extraction_From_Unstructured_Documents_CVPR_2022_paper.html) | CVPR 2022 | 표 약 100만 개, 검출과 구조 인식을 단일 모델로 처리 | 구조 인식 GriTS-Con 0.9846 | 이미지 표의 검출과 구조화 |
| [LayoutLMv3](https://doi.org/10.1145/3503161.3548112) | ACM MM 2022 | 텍스트와 이미지 패치를 함께 마스킹해 사전학습 | PubLayNet mAP 95.1(base, 133M) | 양식과 레이아웃 분석 인코더 |
| [Donut](https://www.ecva.net/papers/eccv_2022/papers_ECCV/html/8042_ECCV_2022_paper.php) | ECCV 2022 | 외부 OCR 없이 이미지에서 구조화 출력 생성 | CORD F1 84.1, LayoutLMv2와 OCR 조합 78.9(arXiv판 수치, 인용 전 ECCV판 대조 필요) | 소형 OCR 없는 판독 |

| [DePlot](https://aclanthology.org/2023.findings-acl.660) | Findings of ACL 2023 | 차트를 표로 변환한 뒤 추론은 LLM에 위임 | 사람 작성 차트 질의에서 미세조정 최고 성능 대비 29.4% 향상 | 차트를 텍스트 표로 변환 |
| [MMLongBench-Doc](https://proceedings.neurips.cc/paper_files/paper/2024/hash/ae0e43289bffea0c1fa34633fc608e92-Abstract.html) | NeurIPS 2024 D&B | 표, 차트, 이미지가 섞인 긴 PDF 질의 1,082개 | 최고 모델 GPT-4o F1 44.9% | 원본 이미지 직접 입력의 한계, 평가 기준 |

## 2. 구조화와 LLM 전달

| [RAPTOR](https://proceedings.iclr.cc/paper_files/paper/2024/hash/8a2acd174940dbca361a6398a4f9df91-Abstract-Conference.html) | ICLR 2024 | 청크를 재귀적으로 군집화, 요약해 트리 구성 | QuALITY 절대 20% 향상(GPT-4) | 문서 계층별 색인 |
| [Self-RAG](https://proceedings.iclr.cc/paper_files/paper/2024/hash/25f7be9694d7b32d5cc670927b8091e1-Abstract-Conference.html) | ICLR 2024(구두 발표) | 검색 필요성, 근거 관련성, 답변 뒷받침 여부를 스스로 판정 | 7B·13B 모델이 ChatGPT 대비 질의응답, 사실 검증 우세 | 근거 부족 시 보류 |
| [ColPali](https://proceedings.iclr.cc/paper_files/paper/2025/hash/99e9e141aafc314f76b0ca3dd66898b3-Abstract-Conference.html) | ICLR 2025 | OCR 없이 페이지 이미지를 다중 벡터로 검색 | ViDoRe nDCG@5 81.3, 기존 파이프라인 67.0. 색인 쪽당 0.39초 | 비교 대상(이미지 검색 방식) |

| [StructGPT](https://aclanthology.org/2023.emnlp-main.574) | EMNLP 2023 | 구조화 데이터 접근 인터페이스로 LLM 추론 | | 구조화 데이터 조회 |

| [vLLM](https://doi.org/10.1145/3600006.3613165) | SOSP 2023 | KV 캐시의 블록 단위 관리 | 같은 지연에서 처리량 2~4배 | 온프레미스 동시 요청 처리 |

| [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/) | TACL 2024 | 입력 내 정보 위치별 성능 측정 | 중간 위치 정보에서 성능 크게 하락 | 긴 문서 전체 입력보다 짧은 근거 입력 |
