# 그림

구상안 전체를 한 장에 담은 그림 두 안. 1장 PPT에 넣을 안을 정한 뒤 나머지는 삭제함.

| 파일 | 구성 | 생성 |
|---|---|---|
| `구상안-전체-그림.svg`, `.png` | 흑백 선 구성(v12). 처리 흐름 6단과 재검증, 표현 수준 표, 사례, 비교군과 실측, 한계, 근거 논문 | `python3 make_fig.py 구상안-전체-그림.svg` 뒤 브라우저 렌더 |
| `구상안-전체-구조.png` | 입력, 전처리, 구조화, 질의 시 활용의 4구역 구성. 연결 원칙과 질문 조건별 결과 | `python3 draw_overview.py` |

글꼴은 Pretendard. 1600×900(16:9) 가로형.
