# v10 표와 이미지에 분산된 정보의 관계와 적용 조건을 보존하는 전처리 및 구조화 방안

작성 2026-10-28

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**핵심 아이디어** 그림, 표, 각주에 나뉘어 기록된 값과 적용 조건을 연결된 형태로 저장하고 질문의 조건에 해당하는 값과 출처를 LLM에 전달함.

**적용 대상** PDF와 스캔 형태의 기술문서(교범, 시험 기준, 규격). CAD 모델과 구조화된 설계 데이터는 제외함.

**설계 전제** 독립 실행 가능한 오픈소스 모델 활용. 제한된 연산 자원을 고려한 처리. 특정 조직의 시스템과 자원 현황은 전제하지 않음.

## 1. 문제

기술문서의 정보는 여러 위치와 형식에 나뉘어 기록됨. 부품의 위치는 그림에, 구역별 기준값은 표에, 적용 조건은 각주에 기재되는 경우가 있음. 텍스트 변환 과정에서 세 정보가 분리되면 값을 정확히 인식하더라도 해당 값의 적용 대상과 조건을 확인할 수 없음. 따라서 문자 인식 정확도와 별개로 정보 간 연결 관계의 보존이 필요함.

## 2. 해결 방안

### 2.1 데이터 전처리

1. **1차 추출** 텍스트 레이어가 있는 문서와 디지털 표는 CPU 기반 파서로 텍스트, 셀, 위치를 추출함. PDF 도면은 벡터 객체와 좌표를 활용함. 스캔 문서와 이미지는 기본 OCR 또는 경량 시각 분석으로 요소와 위치를 확보함.
2. **연결 확인** 각주 기호, 참조 번호, 식별자 등 연결이 예상되는 명시적 참조의 실제 연결 여부를 확인함.
3. **연결 누락 영역 재해석** 예상되는 연결이 없거나 상충하는 경우에 한해 해당 원본 영역에 소형 시각언어모델(VLM)을 적용함.
4. **저장** 대상, 속성 또는 관계, 값, 적용 조건, 출처로 저장하고 질의 시 재사용함.

| 명시적 참조 | 연결 누락 판단 기준 | 재해석 영역 |
|---|---|---|
| 표의 각주 기호 | 대응하는 각주 문장 없음 | 표 하단 영역 |
| 표의 구역명 | 구역 참조가 있는 문서에서 부품의 소속 구역 미확인 | 해당 도면 영역 |

연결 누락 재해석은 명시적 참조가 있는 경우에 적용하는 선택적 오류 복구 방식임. 1차 추출에서 완전히 누락된 객체는 탐지 대상에서 제외됨. 검증 전의 추출값은 확정값으로 취급하지 않음.

**연산 자원 측면** 1차 추출은 CPU에서 수행하고 GPU를 사용하는 시각 모델은 연결 누락 영역에 한정함. 실제 연산량 감소 폭은 재처리 비율에 따라 달라지므로 실험으로 확인함.

### 2.2 데이터 구조화

**정보 구조** 대상, 속성 또는 관계, 값, 적용 조건, 출처로 저장함. 단위는 값과 함께 표기함. 출처는 문서명이 아닌 이미지 영역, 표 셀, 각주 단위로 기록해 잘못된 연결의 원본 확인 근거로 활용함.

**표의 연결** 헤더, 셀, 각주의 관계는 문서 구조를 기준으로 연결함.

**그림의 연결** 부품 라벨과 구역 경계를 추출한 뒤 포함 관계를 확인함. 공간적 근접을 근거로 포함 관계를 확정하지 않으며 경계가 불명확한 경우 원본과 함께 미확정 상태로 보존함.

**적용 조건의 저장** 각주와 구역 등에 분산된 조건을 해당 값에 연결해 저장함. 동일 대상에 조건별로 다른 값이 있으면 각각 보존함.

**질의 시 전달** 질문의 대상과 조건에 해당하는 값, 조건, 출처를 조회해 전달함. 구역의 기준값을 부품 고유의 값으로 해석하지 않음.

**연산 자원 측면** 구조화는 문서 등록 시점에 1회 수행해 재사용함. 질의 시점에는 필요한 값과 조건으로 입력을 한정해 소형 로컬 LLM의 입력량을 줄임.

## 3. 사례

가상 기술문서 기준.

**원본 구성**

- 부품 배치도: 부품 A-17이 2구역 경계 안에 위치
- 구역별 기준 표

| 구역 | 최대 허용 온도 |
|---|---|
| 1구역 | 70°C |
| 2구역 | 80°C*, 95°C** |

\* 정상 운전 조건에서 적용
\** 비상 운전 시 60초 이내 적용

**질문** A-17이 설치된 구역에 적용되는 정상 운전 시 최대 허용 온도 기준

**필요 정보** 배치도의 소속 구역, 표의 구역별 값, 각주의 적용 조건. 어느 하나라도 누락되면 답변 불가.

**구조화 결과**

| 대상 | 속성 또는 관계 | 값 | 적용 조건 | 출처 |
|---|---|---|---|---|
| A-17 | 소속 구역 | 2구역 | 없음 | 부품 배치도의 A-17 라벨과 2구역 경계 |
| 2구역 | 구역별 최대 허용 온도 | 80°C | 정상 운전 | 구역별 기준 표의 2구역 행, 각주 |
| 2구역 | 구역별 최대 허용 온도 | 95°C | 비상 운전, 60초 이내 | 구역별 기준 표의 2구역 행, 각주 |

**질문 조건별 전달 내용**

| 질문 조건 | 전달 내용 |
|---|---|
| 정상 운전 | 80°C, 적용 조건, 출처 |
| 조건 미지정 | 정상 운전 기준 80°C와 비상 운전 기준 95°C 병기 |
| 기록 없는 조건 | 해당 조건의 기준 부재로 답변 보류 |

**연결 누락 재해석 사례** 스캔본에서 각주 문장이 인식되지 않으면 표의 각주 기호가 미연결 참조로 확인됨. 표 하단 영역에 한해 VLM을 재적용해 적용 조건을 확보함.

## 4. 기존 접근과의 차이

일반적인 구성은 문서를 텍스트로 변환해 일정 길이로 분할한 뒤 검색하거나 페이지 이미지를 그대로 검색하는 방식임. 개별 요소는 2026년 연구에서 일부 제안되었으며 이 제안은 해당 요소를 기술문서의 그림, 표, 각주 연결에 맞춘 단일 처리 흐름으로 구성함.

| 구분 | 일반적인 구성과 최신 연구 | 제안 |
|---|---|---|
| 적용 조건 | 각주와 조건을 본문 텍스트의 일부로 처리. 조건부 지식 연결 연구는 의생명 분야 중심(Condition-Gated Reasoning, 2026) | 값마다 적용 조건을 함께 저장. 항공 기술문서 표준 S1000D의 적용성 개념을 PDF와 스캔 문서에 적용 |
| 시각 모델 적용 범위 | 전체 페이지 처리 또는 파싱 품질 기준 재처리(ParseFixer, 2026) | 명시적 참조의 연결 누락 기준으로 재처리 영역 결정 |
| 그림과 표의 연결 | 그림 설명 텍스트 검색 또는 도면 영역 검색(BLUEPRINT, 2026) | 부품 라벨과 구역 경계의 포함 관계 확인 후 표의 기준과 연결 |
| LLM 입력 | 검색된 텍스트 조각 입력 | 질문 조건과 일치하는 값과 출처 전달 |

## 5. 검증

모든 방식은 파싱 결과를 저장해 재사용하는 조건에서 비교함. 측정 전이므로 수치는 기재하지 않음.

| 구분 | 비교 대상 | 지표 |
|---|---|---|
| 전처리 | 전체 페이지 VLM 처리, 파싱 품질 기준 재처리, 연결 누락 영역 한정 처리 | 문서당 GPU 처리 시간 |
| 구조화 | 고정 길이 분할 검색 결과 입력, 관계와 적용 조건을 연결한 정보 입력 | 관계 연결 정확도, 질의응답 정답률, 질의당 입력 토큰 수 |

관계 연결 정확도는 소속 구역, 적용 조건, 출처가 값에 올바르게 연결된 비율로 정의함. 입력 토큰 수는 정답률과 함께 판단하며 구조화로 정답률이 낮아지는 경우도 기록함.

제목: 표와 이미지에 분산된 정보의 관계와 적용 조건을 보존하는 전처리 및 구조화 방안

| 구성 | 내용 |
|---|---|
| 문제 | 그림, 표, 각주의 정보가 텍스트 변환 과정에서 분리될 위험. 요소 유형별로 우수한 파싱 방식이 상이하다는 연구 결과(ParseBench, 2026) |
| 데이터 전처리 | 1차 추출, 명시적 참조의 연결 확인, 연결 누락 영역의 VLM 재해석. 각주 누락 재처리 사례로 제시 |
| 데이터 구조화 | 값과 적용 조건, 출처를 연결해 저장(S1000D 적용성 개념). 등록 시 1회 구조화, 질의 시 필요한 값과 조건으로 입력 한정 |
| 사례 | 부품 배치도, 구역별 기준 표, 각주의 실제 형태와 LLM 전달 과정 도식. 질문 조건별 전달 내용은 한 줄 |
| 검증 | 관계 연결 정확도, 질의응답 정답률, 문서당 GPU 처리 시간, 질의당 입력 토큰 수 |

모델명, 모델별 성능 수치, 하드웨어 사양, 저장 구조, 특정 내부 업무와 시스템은 기재하지 않음.

## 7. 면접 대비

| 예상 질문 | 답변 요지 |
|---|---|
| 래스터 도면의 경계 추출 신뢰도 | 소형 문서 모델의 레이아웃 인식 성능은 제한적(Granite-Docling 모델 카드 기준 mAP 0.27). PDF 도면은 벡터 객체와 좌표를 우선 활용. 래스터 도면에서 추출에 실패하면 미확정 처리 후 담당자 확인 |
| 식별자 표기 불일치 | A-17, A17, A-17-01 등 문서별 표기 규칙을 정규화한 뒤 대조. 정규화로 해결되지 않으면 미확정 |
| 문서 버전 혼재 | 출처에 문서 버전 포함. 서로 다른 버전의 표와 그림은 연결을 확정하지 않음 |
| CPU 전용 환경 | 소형 문서 모델도 CPU에서는 쪽당 수십 초 수준으로 대량 처리에 부적합. GPU 1장 수준 필요 |
| 재처리 검증 방식 | 추출 결과를 원본 영역에 다시 렌더링해 대조하는 방식(RaV-IDP, 2026)을 보조 수단으로 활용 가능 |
