# v7: 표·이미지의 구조와 적용 조건을 보존하는 데이터 전처리·구조화 방안

작성 2026-10-28. v6 확정안의 기술 방향을 유지하고 사례와 표현을 수정함. 세부 기술보다 아이디어 중심의 소개 방식으로 정리함.

**주제:** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**핵심 아이디어:** 표와 이미지에서 추출한 값을 그 값의 적용 조건과 원본 위치까지 연결해 LLM에 전달함.

**설계 전제:** 독립 실행 가능한 오픈소스 모델 활용. 제한된 연산 자원을 고려한 효율적 처리. 특정 조직의 시스템이나 자원 상황을 전제하지 않음.

## 0. v6 대비 변경

| v6 | v7 | 사유 |
|---|---|---|
| 표와 각주로 구성된 A-17 사례 | 부품 위치도, 운용 기준 표, 각주가 연결되는 사례 | 표와 이미지를 함께 다루는 문제로 구체화 |
| 구조화 단계의 처리 방식 불명확 | 명시적 관계는 규칙, 해석이 필요한 관계는 소형 모델, 불명확한 연결은 미확정 | 문서 VLM은 구조 추출 모델이며 의미 판별 모델이 아님 |
| 필요한 영역에 소형 문서 VLM | 이미지 기반 해석이 필요한 페이지 또는 영역에 문서 VLM | 스캔본은 영역 탐지 선행 필요. 도식은 과도한 분할 시 맥락 손실 |
| 의미·관계 보존형 구조화, 질문별 입력 구성 | 값과 적용 조건을 함께 저장, 질문에 필요한 값과 근거로 입력 구성 | 실제 동작이 드러나는 표현 |
| 7개 필드 스키마, 상태 3단계, 저장 표현 3종, 질문 유형 4종 | 대상, 값, 조건, 출처 네 묶음 | 1장 전달력 |
| 기술 후보 모델 비교표 | 삭제(기술 노트에 보존) | 모델 선정은 주제가 아님 |
| 입력 토큰 실측 표시 | 기대 효과와 검증 지표로 표시 | 측정 전 수치 기재 불가 |

## 1. 문제

기술문서의 정보는 한 곳에 있지 않음. 부품은 그림에, 수치는 표에, 적용 조건은 각주나 본문에 있음. 텍스트 변환이나 고정 길이 분할 과정에서 이 연결이 끊어지면 LLM은 값을 찾더라도 그 값이 어떤 조건에서 유효한지 알 수 없음.

원본 이미지를 질의 때마다 멀티모달 모델에 입력하는 방식은 이미지 처리와 입력 문맥이 반복적으로 증가함.

참고 근거로 ParseBench(2026)는 기업 문서 약 2,000쪽 평가에서 하나의 처리 방식이 표, 차트, 원본 위치 등 모든 항목에서 우수하지 않다는 결과를 보고함.

## 2. 해결 방안

### 2.1 데이터 전처리

**원본 직접 추출.** 텍스트 레이어가 있는 문서와 디지털 표는 파서로 텍스트, 셀, 위치를 추출함.

**선택적 문서 VLM 적용.** 이미지 기반 해석이 필요한 페이지 또는 영역에 한해 경량 문서 VLM을 적용함. 추출이 불완전한 영역에 한해 재처리함. 검증 전의 추출값은 확정된 사실로 취급하지 않음.

### 2.2 데이터 구조화

**값과 적용 조건을 함께 저장.** 추출한 정보를 대상, 값, 조건, 출처 네 묶음으로 저장함. 표의 헤더와 셀, 이미지의 객체와 주석, 각주의 적용 조건을 동일한 대상 기준으로 연결함.

| 관계 유형 | 예시 | 연결 방식 |
|---|---|---|
| 명시적 관계 | 같은 행의 값, 헤더와 단위, 각주 번호 | 구조 규칙 |
| 해석이 필요한 관계 | 그림 지시선의 대상, 조건 문장의 적용 범위 | 필요한 경우에 한해 소형 모델 |
| 불명확한 관계 | 근거가 부족한 연결 | 확정하지 않고 원본과 함께 보존 |

해석이 필요한 관계에서는 모델 호출이 추가됨. 해당 비용은 문서 등록 시점에 1회 발생함.

**질문에 필요한 값과 근거로 입력 구성.** 질의 시점에는 저장된 정보에서 질문에 필요한 값, 조건, 출처를 찾아 LLM에 전달함. 필요한 대상, 값, 조건이 빠진 경우 추가 조회함.

### 2.3 제한된 연산 자원과의 관계

구조화를 문서 등록 시점에 마쳐 질의 때마다 반복되는 이미지 처리를 줄임. 질문에 필요한 근거로 입력을 한정해 입력량을 줄임. 효율화는 별도 기술이 아니라 위 두 단계의 결과임.

## 3. 사례: 가상 기술문서

**원본 구성**

- 이미지: 부품 위치도(A-17 표기)
- 표: 운용 기준

| 대상 | 온도 |
|---|---|
| A-17 | 80°C* |

\* 정상 운전 시 적용

**처리 결과 비교**

| 방식 | 결과 |
|---|---|
| 기존 방식 | 이미지의 A-17, 표의 온도, 각주의 적용 조건이 별개의 텍스트로 처리될 가능성 |
| 제안 방식 | 대상 A-17, 허용 온도 80°C, 정상 운전 조건, 출처(이미지 객체, 표 셀, 각주)를 하나로 연결 |

기존 방식에서도 각주가 올바르게 인식될 수 있음. 비교 실험에서는 정답 여부와 함께 세 정보의 연결 유지 여부를 측정함.

## 4. 기대 효과와 검증 지표

측정 전이므로 수치는 기재하지 않음.

| 지표 | 내용 |
|---|---|
| 정보 추출 정확도 | 수치와 텍스트 값의 일치율 |
| 조건·관계 보존 정확도 | 값과 적용 조건, 이미지 객체, 출처의 연결 일치율 |
| 최종 QA 정답률 | 동일 질의 집합의 정답률 |
| 질의당 처리 비용 | 입력 토큰, 이미지 처리 횟수 |

비교 대상은 일반 OCR 기반 텍스트 분할, 구조 보존 분할, 제안 방식 세 가지. 1장에는 비교 대상을 간략히 표시함.

## 5. 1장 구성

제목: 표·이미지의 구조와 적용 조건을 보존하는 데이터 전처리·구조화 방안

- 문제: 그림, 표, 각주에 분산된 정보의 연결 손실
- 데이터 전처리: 원본 직접 추출, 선택적 문서 VLM
- 데이터 구조화: 값과 적용 조건을 함께 저장, 질문에 필요한 값과 근거로 입력 구성
- 사례: 부품 위치도, 운용 기준 표, 각주의 연결(중심 배치)
- 검증 지표 4개

모델명, 질문 유형별 처리, 저장 형식 세부는 1장에 포함하지 않음. 특정 내부 업무와 시스템은 언급하지 않음.
