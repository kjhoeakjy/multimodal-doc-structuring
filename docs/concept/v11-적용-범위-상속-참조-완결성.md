# v11 표와 이미지에 분산된 정보의 적용 범위를 보존하는 전처리 및 구조화 방안

작성 2026-10-28. v10을 주요 학회 게재 논문을 중심축으로 전면 재편한 안. 중심 근거는 학회 게재 논문으로 한정하고 프리프린트는 동향 참고에 둠.

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**과제 정의** 기술문서의 값은 적용 조건이 표 머리글, 주의문, 각주, 일반 주기, 그림의 포함 관계에 나뉘어 기록됨. 질문에 대해 값과 함께 그 값이 유효한 조건과 출처를 답하고 조건이 지정되지 않으면 조건별 값을 병기하며 기록에 없는 조건이면 적용 범위를 밝히고 보류하는 과제임. 조건부 답변 과제(ConditionalQA, ACL 2022)와 표와 본문이 섞인 문서의 질의응답(TAT-QA, ACL 2021)을 그림과 스캔 문서가 포함된 기술문서로 확장한 것임.

**핵심 아이디어** 값이 놓인 문서 구조에서 그 값의 적용 범위를 상속해 함께 저장함. 문서 내부 참조의 완결성으로 추출 오류를 찾아 해당 영역에 한해 재추출함. 질문의 조건과 적용 범위가 일치하는 값을 로컬 LLM에 전달함.

**적용 대상** PDF와 스캔 형태의 기술문서(정비 교범, 시험 기준, 규격, 도면). CAD 모델과 구조화된 설계 데이터는 제외함.

**설계 전제** 독립 실행 가능한 오픈소스 모델 활용. 제한된 연산 자원을 고려한 처리. 특정 조직의 시스템과 자원 현황은 전제하지 않음.

**구성 원칙** 각 처리 단계는 주요 학회에 게재된 검증된 방법을 사용함. 지원자의 기여는 적용 범위 상속, 참조 완결성 기반 재추출, 적용 범위 일치 기반 전달의 세 원리에 둠.

## 1. 문제

기술문서의 값은 그 자체로 완결되지 않음. 토크 값은 표 상단 주의문의 나사산 조건, 상위 머리글의 하중 조건, 하위 머리글의 너트 종류, 계열 구분 행의 나사 계열에 따라 달라짐. 도면의 공차는 일반 주기의 기본값과 개별 표기의 예외로 결정됨. 텍스트 변환이나 고정 길이 분할에서 이 구조가 사라지면 값을 정확히 읽더라도 적용 범위를 확인할 수 없음.

| 근거 | 학회 | 내용 |
|---|---|---|
| MMLongBench-Doc | NeurIPS 2024 | 표, 차트, 이미지가 섞인 긴 PDF 질의에서 최고 모델도 F1 44.9% |
| TableRAG | NeurIPS 2024 | 표 전체를 입력하면 정확도 4.6, 필요한 셀을 검색해 입력하면 49.2 |
| Lost in the Middle | TACL 2024 | 입력 중간에 놓인 정보는 활용 성능이 크게 하락 |
| ConditionalQA | ACL 2022 | 답과 함께 그 답이 유효한 조건을 내는 과제. 모델은 조건 식별에서 가장 취약 |
| TAT-QA | ACL 2021 | 표와 주변 본문을 함께 읽어야 답하는 질의응답. 단위와 배율이 본문에 있음 |

원본 이미지나 문서 전체를 그대로 입력하는 방식은 정확도와 연산 양면에서 한계가 있으며 적용 범위를 보존한 구조화가 필요함.

기존 연구는 이 문제를 나누어 다룸. 조건부 답변(ConditionalQA)은 긴 텍스트 문서가 대상이고 표와 본문의 결합(TAT-QA)은 디지털 재무 문서가 대상이며 여러 쪽과 여러 형식에 걸친 근거(MMLongBench-Doc, SPIQA)는 평가 과제로 정의됨. 세 문제가 한 문서 안에서 동시에 나타나는 기술문서를 전처리와 구조화 관점에서 다룬 학회 논문은 확인되지 않음.

## 3. 제안 방법

### 3.1 적용 범위 상속

모든 값은 자신을 둘러싼 문서 구조에서 적용 범위를 상속함. 상속 경로는 문서 요소의 포함 관계로 정의함.

| 문서 요소 | 상속 경로 | 예외 규칙 |
|---|---|---|
| 표 | 표 제목, 주의문, 상위 머리글(여러 열에 걸친 머리글), 하위 머리글, 계열 구분 행, 셀, 각주 기호 | 각주가 해당 셀의 범위를 추가 또는 한정 |
| 도면 주기 | 일반 주기(별도 표기가 없는 한 적용) | 개별 공차 표기가 일반 주기를 대체 |
| 그림 | 구역 경계와 부품 상자의 포함 관계 | 경계 판독이 불명확하면 상속을 확정하지 않음 |

값 하나의 적용 범위는 상속 경로에 있는 조건의 결합으로 저장함. 항공 기술문서 표준 S1000D가 데이터 모듈에 부여하는 적용성 정보를 그 구조가 없는 PDF와 스캔 문서에서 복원하는 방법에 해당함.

### 3.2 참조 완결성 기반 선택적 재추출

문서 내부의 참조는 반드시 대상을 가짐. 이 제약이 깨진 곳을 추출 오류 후보로 판단함.

| 참조 유형 | 완결성 조건 | 재추출 영역 |
|---|---|---|
| 각주 기호 | 표의 기호마다 대응 각주 문장 존재 | 표 하단 |
| 표의 격자 | 행마다 열 수가 머리글 열 수와 일치, 값 형식 일치 | 해당 행 |
| 주기 번호와 공차 기호 | 공차 값과 데이텀이 있으면 공차 종류 기호 존재 | 해당 주기의 공차 기입 틀 |
| 식별자 | 표의 구역, 부품 번호가 그림에서 확인됨 | 해당 그림 영역 |
| 그림 번호와 표 행 | 그림의 체결부 수와 표의 행 수가 일치, 번호 중복 없음 | 해당 번호 주변, 표 영역 |
| 단위 | 수치마다 단위가 머리글 또는 각주에 존재 | 머리글, 각주 |

처리 순서는 전체 기본 추출, 구조화와 완결성 점검, 위반 영역의 재추출, 저장 순임. 전체 문서는 가벼운 1차 처리로 추출하고 GPU를 쓰는 시각 모델은 위반 영역에 한정함. 재추출은 고해상도 재처리, 소형 시각언어모델(VLM) 순으로 적용하고 횟수를 제한함. 재추출 결과는 1차 추출 결과와 대조해 유사도가 낮으면 채택하지 않음. 1차 추출에서 완전히 누락된 객체는 탐지 대상이 아니므로 원본과의 표본 대조로 보완함.

### 3.3 적용 범위 일치 기반 근거 전달

질문을 대상, 속성, 조건으로 나누고 저장된 값의 적용 범위와 대조함.

| 경우 | 전달 내용 |
|---|---|
| 질문 조건과 적용 범위 일치 | 해당 값, 적용 범위, 출처 |
| 질문에 조건 없음 | 조건별 값 병기 |
| 질문 조건이 적용 범위 밖 | 적용 범위를 밝히고 답변 보류 |

수치는 LLM이 생성하지 않고 저장된 값을 그대로 전달함(DATER의 실행 기반 수치 산출과 같은 원칙). 구조화는 문서 등록 시 1회 수행해 재사용하고 질의 시 입력을 일치하는 항목에 한정해 소형 로컬 LLM의 입력량을 줄임.

### 3.4 사례

합성 정비 문서 기준. 그림 1 조립도(부품 상자 4개, 원 안 번호 체결부 8개, 체결부 3은 HV-202 상자 안), 표 1 체결부 토크(1 M6 10 *, 2 M10 48 *, 3 M8 25 *), 각주 "* 건식 나사산 기준. 윤활 시 M6 8, M8 20, M10 38 N·m".

| 대상 | 속성 또는 관계 | 값 | 적용 범위 | 출처 |
|---|---|---|---|---|
| 체결부 3 | 소속 부품 | HV-202 | 없음 | 그림 1 체결부 3 원, HV-202 상자 |
| 체결부 3 | 규격 | M8 | 없음 | 표 1 3행 |
| 체결부 3 | 토크 | 25 N·m | 건식 나사산 | 표 1 3행 |
| 체결부 3 | 토크 | 20 N·m | 윤활 | 표 1 각주 * |

질문 "HV-202를 고정하는 체결부의 윤활 조건 토크 값"에는 20 N·m, 윤활, 출처를 전달함. 조건이 없으면 건식 25 N·m와 윤활 20 N·m를 병기하고 기록에 없는 조건이면 두 범위를 밝히고 보류함.

실제 문서(FAA AC 43.13-1B 표 7-1)에서는 값 하나의 적용 범위가 나사 계열, 너트 종류, 하중 조건, 도금 조건, 추정값 표시의 다섯 겹이며 상속 경로로 모두 연결됨.

## 4. 기존 연구와의 차이

| 연구 | 학회 | 차이 |
|---|---|---|
| TableRAG | NeurIPS 2024, EMNLP 2025 | 표 안의 셀 검색과 실행에 집중. 주의문, 다단 머리글, 각주에서 오는 적용 범위를 값에 상속하지 않음 |
| HippoRAG | NeurIPS 2024 | 텍스트 개체 간 그래프. 표와 그림의 문서 구조에서 범위를 도출하지 않음 |
| Self-RAG | ICLR 2024 | 학습된 판정 토큰으로 근거 관련성 판단. 질문 조건과 값의 적용 범위를 명시적으로 대조하지 않음 |
| ColPali, VisRAG | ICLR 2025 | 페이지 이미지를 그대로 검색하고 판독. 구조화 결과를 재사용하지 않아 질의마다 시각 처리 필요 |
| Donut, Nougat | ECCV 2022, ICLR 2024 | 페이지 단위 변환. 어느 영역을 다시 읽어야 하는지 판단하는 기준이 없음 |
| ConditionalQA | ACL 2022 | 텍스트 문서의 조건부 답변 과제. 표, 그림, 각주, 스캔 문서에서 조건을 도출하는 전처리 없음 |
| TAT-QA | ACL 2021 | 디지털 재무 보고서의 표와 본문 결합. 그림과 적용 조건 없음 |
| Adaptive-RAG | NAACL 2024 | 질문 난이도로 처리 경로 선택. 본 방안은 문서 영역 단위로 추가 처리 여부를 선택 |
| MoLoRAG | EMNLP 2025 | 쪽 사이의 논리 관계 그래프로 검색. 값 단위의 적용 범위 없음 |

| 구분 | 비교 대상 | 지표 |
|---|---|---|
| 전처리 | 고정 길이 분할, Docling 기본 파이프라인, 소형 문서 VLM 페이지 전체 변환, 제안 | 문서당 처리 시간, 시각 모델 호출 수, 값과 적용 범위 추출 정확도, 재추출 선별의 정밀도와 재현율, 미해결 참조 수 |
| 구조화와 전달 | 위 전처리 결과의 검색 입력, 페이지 이미지 직접 입력(ColPali, VisRAG 계열), 제안 | 질의응답 정답률, 조건 혼동 오답률, 적절한 보류 비율, 질의당 입력 토큰 수 |
| 구성 요소 제거 | 적용 범위 상속 제외, 완결성 점검 제외, 범위 일치 전달 제외 | 같음 |

## 6. 연구 확장

공개 기술문서(연방항공청 자문 회람, 표준 기관 시험 도면, 공개 교범)로 값, 적용 범위, 출처 위치가 표기된 질의 벤치마크를 구축함. 완결성 점검의 탐지 정밀도와 재현율, 정확도와 연산량의 관계를 정량화함. 참조 유형 판정을 규칙에서 소형 모델 학습으로 일반화함.

## 7. 1장 구성

제목: 표와 이미지에 분산된 정보의 적용 범위를 보존하는 전처리 및 구조화 방안

| 구성 | 내용 |
|---|---|
| 문제 | 값의 적용 범위가 주의문, 머리글, 각주, 그림에 분산. 원본 직접 입력의 한계(MMLongBench-Doc, NeurIPS 2024) |
| 데이터 전처리 | 학회 검증 모델로 전체 기본 추출(DocLayNet, TableFormer). 참조 완결성 위반 영역에 한해 소형 시각 모델 재추출 |
| 데이터 구조화 | 적용 범위 상속으로 값마다 조건과 출처 저장. 질문 조건과 일치하는 값 전달, 범위 밖이면 보류 |
| 사례 | FAA 토크 표의 값 하나가 주의문, 머리글, 계열 행, 각주에서 조건을 상속하는 도식 |
| 검증 | 공개 원본 실측. 처리 시간, 추출 정확도, 정답률, 입력 토큰 |

모델명, 하드웨어 사양, 저장 형식 세부는 1장에 포함하지 않음.

## 8. 면접 대비

| 예상 질문 | 답변 요지 |
|---|---|
| 어느 논문을 기반으로 했는가 | 과제 정의는 ConditionalQA와 TAT-QA, 전처리 구성 요소는 DocLayNet과 TableFormer, 근거 전달은 TableRAG와 Self-RAG. 더한 것은 적용 범위 상속과 참조 완결성 기준 재추출 두 가지 |
| 문서마다 규칙을 새로 만드는가 | 제약의 종류(기호와 정의의 대응, 번호와 행의 대응, 열 수, 표기 문법, 단위)는 공통이고 문서 유형은 어떤 제약이 적용되는지로 구분됨. 세 풀을 같은 제약 집합으로 처리함 |
| 전체 페이지 VLM보다 나은가 | 같은 쪽에서 제안 0.2초, 소형 VLM 전체 120초(실측). 정확도는 질의응답 비교로 확인 중 |
| 추출 단계에서 빠진 객체는 어떻게 찾는가 | 참조 완결성으로는 찾지 못함. 원본과의 표본 대조와 중요 값의 별도 확인으로 보완함 |
| 논문으로 발전시킨다면 | 공개 문서로 조건 분산 질문 벤치마크를 구축하고 제거 실험과 비용 대비 정확도 곡선을 더함 |
