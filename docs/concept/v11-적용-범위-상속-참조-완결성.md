# v11 표와 이미지에 분산된 정보의 적용 범위를 보존하는 전처리 및 구조화 방안

작성 2026-10-28

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**핵심 아이디어** 값이 놓인 문서 구조로부터 그 값의 적용 범위를 상속해 함께 저장함. 문서 내부 참조의 완결성으로 추출 오류를 찾아 해당 영역에 한해 재추출함. 질문의 조건과 적용 범위가 일치하는 값을 로컬 LLM에 전달함.

**적용 대상** PDF와 스캔 형태의 기술문서(정비 교범, 시험 기준, 규격, 도면). CAD 모델과 구조화된 설계 데이터는 제외함.

**설계 전제** 독립 실행 가능한 오픈소스 모델 활용. 제한된 연산 자원을 고려한 처리. 특정 조직의 시스템과 자원 현황은 전제하지 않음.

**구성 원칙** 각 처리 단계는 주요 학회에 게재된 검증된 방법을 사용함. 지원자의 기여는 적용 범위 상속, 참조 완결성 기반 재추출, 적용 범위 일치 기반 전달의 세 원리에 둠.

## 1. 문제

기술문서의 값은 그 자체로 완결되지 않음. 토크 값은 표 상단 주의문의 나사산 조건, 상위 머리글의 하중 조건, 하위 머리글의 너트 종류, 계열 구분 행의 나사 계열에 따라 달라짐. 도면의 공차는 일반 주기의 기본값과 개별 표기의 예외로 결정됨. 텍스트 변환이나 고정 길이 분할에서 이 구조가 사라지면 값을 정확히 읽더라도 적용 범위를 확인할 수 없음.

| 근거 | 학회 | 내용 |
|---|---|---|
| MMLongBench-Doc | NeurIPS 2024 | 표, 차트, 이미지가 섞인 긴 PDF 질의에서 최고 모델도 F1 44.9% |
| TableRAG | NeurIPS 2024 | 표 전체를 입력하면 정확도 4.6, 필요한 셀을 검색해 입력하면 49.2 |
| Lost in the Middle | TACL 2024 | 입력 중간에 놓인 정보는 활용 성능이 크게 하락 |

원본 이미지나 문서 전체를 그대로 입력하는 방식은 정확도와 연산 양면에서 한계가 있으며 적용 범위를 보존한 구조화가 필요함.

## 2. 기반 연구

| 단계 | 사용 방법 | 학회 |
|---|---|---|
| 레이아웃 영역 구분 | DocLayNet으로 학습한 레이아웃 모델 | KDD 2022 |
| 표 구조 인식 | TableFormer, PubTables-1M 기반 표 모델 | CVPR 2022 |
| 이미지 영역 판독 | Donut 계열 OCR 없는 소형 문서 모델 | ECCV 2022 |
| 차트 변환 | DePlot의 차트에서 표로의 변환 | Findings of ACL 2023 |
| 표 근거 전달 | TableRAG의 셀 단위 검색, Chain-of-Table과 DATER의 하위 표 축소와 실행 기반 수치 산출 | NeurIPS 2024, ICLR 2024, SIGIR 2023 |
| 분산 정보 연결 | HippoRAG의 그래프 기반 연결 | NeurIPS 2024 |
| 근거 부족 시 보류 | Self-RAG의 근거 뒷받침 판정 | ICLR 2024 |
| 로컬 LLM 효율화 | AWQ 4비트 양자화, LongLLMLingua 입력 압축 | MLSys 2024, ACL 2024 |

처리 도구는 위 모델을 통합한 공개 도구(Docling)와 소형 문서 VLM(Granite-Docling 258M)을 사용함.

## 3. 제안 방법

### 3.1 적용 범위 상속

모든 값은 자신을 둘러싼 문서 구조로부터 적용 범위를 상속함. 상속 경로는 문서 요소의 포함 관계로 정의함.

| 문서 요소 | 상속 경로 | 예외 규칙 |
|---|---|---|
| 표 | 표 제목, 주의문, 상위 머리글(여러 열에 걸친 머리글), 하위 머리글, 계열 구분 행, 셀, 각주 기호 | 각주가 해당 셀의 범위를 추가 또는 한정 |
| 도면 주기 | 일반 주기(별도 표기가 없는 한 적용) | 개별 공차 표기가 일반 주기를 대체 |
| 그림 | 구역 경계와 부품 상자의 포함 관계 | 경계 판독이 불명확하면 상속을 확정하지 않음 |

값 하나의 적용 범위는 상속 경로에 있는 조건의 결합으로 저장함. 항공 기술문서 표준 S1000D가 데이터 모듈에 부여하는 적용성 정보를 그 구조가 없는 PDF와 스캔 문서에서 복원하는 방법에 해당함.

### 3.2 참조 완결성 기반 선택적 재추출

문서 내부의 참조는 반드시 대상을 가짐. 이 제약이 깨진 곳을 추출 오류 후보로 판단함.

| 참조 유형 | 완결성 조건 | 재추출 영역 |
|---|---|---|
| 각주 기호 | 표의 기호마다 대응 각주 문장 존재 | 표 하단 |
| 표의 격자 | 행마다 열 수가 머리글 열 수와 일치, 값 형식 일치 | 해당 행 |
| 주기 번호와 공차 기호 | 공차 값과 데이텀이 있으면 공차 종류 기호 존재 | 해당 주기의 공차 기입 틀 |
| 식별자 | 표의 구역, 부품 번호가 그림에서 확인됨 | 해당 그림 영역 |

처리 순서는 전체 기본 추출, 구조화와 완결성 점검, 위반 영역의 재추출, 저장 순임. 전체 문서는 가벼운 1차 처리로 추출하고 GPU를 쓰는 시각 모델은 위반 영역에 한정함. 재추출 결과는 1차 추출 결과와 대조해 유사도가 낮으면 채택하지 않음. 1차 추출에서 완전히 누락된 객체는 탐지 대상이 아니므로 원본과의 표본 대조로 보완함.

### 3.3 적용 범위 일치 기반 근거 전달

질문을 대상, 속성, 조건으로 나누고 저장된 값의 적용 범위와 대조함.

| 경우 | 전달 내용 |
|---|---|
| 질문 조건과 적용 범위 일치 | 해당 값, 적용 범위, 출처 |
| 질문에 조건 없음 | 조건별 값 병기 |
| 질문 조건이 적용 범위 밖 | 적용 범위를 밝히고 답변 보류 |

수치는 LLM이 생성하지 않고 저장된 값을 그대로 전달함(DATER의 실행 기반 수치 산출과 같은 원칙).

## 4. 기존 연구와의 차이

| 연구 | 학회 | 차이 |
|---|---|---|
| TableRAG | NeurIPS 2024, EMNLP 2025 | 표 안의 셀 검색과 실행에 집중. 주의문, 다단 머리글, 각주에서 오는 적용 범위를 값에 상속하지 않음 |
| HippoRAG | NeurIPS 2024 | 텍스트 개체 간 그래프. 표와 그림의 문서 구조에서 범위를 도출하지 않음 |
| Self-RAG | ICLR 2024 | 학습된 판정 토큰으로 근거 관련성 판단. 질문 조건과 값의 적용 범위를 명시적으로 대조하지 않음 |
| ColPali, VisRAG | ICLR 2025 | 페이지 이미지를 그대로 검색하고 판독. 구조화 결과를 재사용하지 않아 질의마다 시각 처리 필요 |
| Donut, Nougat | ECCV 2022, ICLR 2024 | 페이지 단위 변환. 어느 영역을 다시 읽어야 하는지 판단하는 기준이 없음 |

## 5. 검증

### 5.1 데이터

| 풀 | 문서 | 원본 |
|---|---|---|
| 정비·수리 지침 | FAA AC 43.13-1B 7장 표 7-1 권장 토크 값 | faa.gov 공개 |
| 엔지니어링 도면 | NIST 제품 제조 정보 시험 도면 FTC 6~11 일반 주기 | nist.gov 공개 |
| 정비 계획 문서 | 구역 위치도, 구역별 점검 주기, 운용 환경 각주 | 합성 |

### 5.2 현재까지 측정 결과(GPU 없는 노트북, CPU 16스레드)

| 항목 | 결과 |
|---|---|
| 토크 표 디지털 원본 | 값 100개 전부 추출, 값마다 나사 계열, 너트 종류, 하중 조건, 주의문, 추정값 각주 상속. 0.2초 |
| 토크 표 완결성 점검 | 열 수 불일치(5열 중 4열)를 탐지해 표 범위 결정 방식 수정 |
| 토크 표 스캔 변형 | 기울기 보정과 OCR 혼동 규칙 적용 후 99/100. 각주 미연결을 탐지해 표 하단 재추출로 복구(22초) |
| 전처리 시간(1쪽) | 제안 0.2초, Docling 기본 파이프라인 19초, 소형 문서 VLM 페이지 전체 변환 120초 |
| 도면 주기 | 6개 도면 중 4개에서 공차 기호 누락 탐지, PDF 벡터 객체로 면의 윤곽도 판별. 시각 모델 미사용 |
| 시각 모델 출력 | 작은 영역 재해석에서 문서에 없는 문장 생성 사례 확인. 1차 추출과의 대조로 기각 |

질의응답 정답률, 조건 혼동 오답률, 질의당 입력 토큰 비교는 실행 중이며 완료 후 기재함.

### 5.3 비교와 지표

| 구분 | 비교 대상 | 지표 |
|---|---|---|
| 전처리 | 고정 길이 분할, Docling 기본 파이프라인, 소형 문서 VLM 페이지 전체 변환, 제안 | 문서당 처리 시간, 시각 모델 호출 수, 값과 적용 범위 추출 정확도 |
| 구조화와 전달 | 위 전처리 결과의 검색 입력, 페이지 이미지 직접 입력(ColPali, VisRAG 계열), 제안 | 질의응답 정답률, 조건 혼동 오답률, 적절한 보류 비율, 질의당 입력 토큰 수 |
| 구성 요소 제거 | 적용 범위 상속 제외, 완결성 점검 제외, 범위 일치 전달 제외 | 같음 |

## 6. 연구 확장

공개 기술문서(연방항공청 자문 회람, 표준 기관 시험 도면, 공개 교범)로 값, 적용 범위, 출처 위치가 표기된 질의 벤치마크를 구축함. 완결성 점검의 탐지 정밀도와 재현율, 정확도와 연산량의 관계를 정량화함. 참조 유형 판정을 규칙에서 소형 모델 학습으로 일반화함.

## 7. 1장 구성

제목: 표와 이미지에 분산된 정보의 적용 범위를 보존하는 전처리 및 구조화 방안

| 구성 | 내용 |
|---|---|
| 문제 | 값의 적용 범위가 주의문, 머리글, 각주, 그림에 분산. 원본 직접 입력의 한계(MMLongBench-Doc, NeurIPS 2024) |
| 데이터 전처리 | 학회 검증 모델로 전체 기본 추출(DocLayNet, TableFormer). 참조 완결성 위반 영역에 한해 소형 시각 모델 재추출 |
| 데이터 구조화 | 적용 범위 상속으로 값마다 조건과 출처 저장. 질문 조건과 일치하는 값 전달, 범위 밖이면 보류 |
| 사례 | FAA 토크 표의 값 하나가 주의문, 머리글, 계열 행, 각주로부터 조건을 상속하는 도식 |
| 검증 | 공개 원본 실측. 처리 시간, 추출 정확도, 정답률, 입력 토큰 |

모델명, 하드웨어 사양, 저장 형식 세부는 1장에 포함하지 않음.
