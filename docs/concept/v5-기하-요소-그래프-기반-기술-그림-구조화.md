# v5 기하 요소 그래프를 공통 표현으로 하는 기술 그림의 전처리 및 구조화

작성 2026-10-29. 세부 설계, 근거, 실험은 [v5-상세.md](v5-상세.md).

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**전제** 생성형 VLM 미사용. 폐쇄망, 제한된 GPU, 기존 텍스트 LLM.

## 핵심

기술 그림(설계도면, 단면도, 회로도, 계통도, 그래프)은 모두 선, 원호, 문자, 화살표, 닫힌 영역, 기호의 조합임. 모든 그림을 이 요소와 요소 간 관계(접속, 교차, 포함, 지시)의 그래프로 바꾸고 텍스트로 직렬화해 기존 텍스트 LLM에 전달함.

## 근거

텍스트 LLM은 저수준 SVG 코드(평균 54.9)보다 노드와 연결이 명시된 표현(Graphviz 84.5)에서 그림을 훨씬 정확히 추론함(VGBench, EMNLP 2024). 멀티모달 모델의 도면 실패도 문자 판독이 아니라 요소 간 관계에서 발생함(AECV-Bench 2026, MechVQA ICML 2026). 따라서 전처리의 목표는 그림을 관계가 명시된 그래프로 바꾸는 것임.

## 구성

| 단계 | 처리 |
|---|---|
| 1. 요소 추출 | 벡터 원본(PDF, DXF, SVG)은 직접 추출. 스캔은 선과 원호 벡터화, OCR |
| 2. 그래프 구성 | 요소를 노드, 기하 관계를 간선으로. 연결 성분과 반복 패턴은 상위 노드로 묶음 |
| 3. 해석 | 유형별 해석기가 의미 부여. 기계도면은 치수와 형상의 전역 할당, 계통도는 연결망, 차트는 축과 계열, 표는 셀. 해석기 없는 그림은 그래프 자체로 처리 |
| 4. 검증 | 설명률(원본 요소 중 그래프로 설명된 비율)과 기하 제약(치수선 길이와 표기 값 일치, 선의 연결 완결, 뷰 간 일치). 확정, 후보, 기각 |
| 5. 검색과 응답 | 그래프 텍스트 검색, 이미지 임베딩, 식별자 조회. LLM에는 질문 관련 부분 그래프와 확정 정보 전달. 미해석 부분은 원본 영역 제시 |

## 평가

CAD에서 도면을 생성(FreeCAD TechDraw)하면 치수와 형상, 부품과 영역의 대응이 정답으로 남음. 이를 DXF, 벡터 PDF, 스캔 형태로 출력해 사람 라벨 없이 변환과 해석 정확도를 측정함.

## 경쟁 포인트

1. 그림을 텍스트 LLM이 추론 가능한 관계 명시 그래프로 변환함. VLM 없이 기존 LLM으로 그림 질의응답이 가능해짐
2. 설명률과 기하 제약으로 해석 결과를 검증하고 못 읽은 부분을 명시함

## 범위

모든 그림의 검색과 위치 지정, 해석기 있는 유형의 수치와 관계 질의를 지원함. 해석기 없는 유형의 질의 정확도는 측정 대상임. 사진과 음영 렌더링은 이미지 검색에 한정함. "모든 그림을 완전히 이해"가 아니라 "모든 그림을 동일한 검증 가능한 표현으로 바꾸고 미해석 부분을 명시"가 주장 범위임.
