# v3 복잡한 기술도면의 시각, 기하, 의미 정보 보존을 위한 적응형 전처리 및 검색

작성 2026-10-29. v2의 시각 임베딩과 유형별 구조 추출을 유지하고 원본 벡터와 기하 정보 우선 처리, 검증 기반 확정, 독립 평가를 추가한 안.

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**목표** PDF, 스캔, 표, 복합 기술 삽화, 2D 도면, 계통도, 3D CAD의 시각 정보를 검색 가능하게 색인하고 검증 가능한 기술정보(치수, 규격, 부품, 연결, 적용 조건)를 별도 구조로 추출해 폐쇄망 온프레미스의 기존 텍스트 LLM이 근거와 함께 활용하도록 함.

**설계 전제** 생성형 시각언어모델(VLM) 미사용. 폐쇄망, 제한된 GPU, 기존 텍스트 LLM. 특정 조직의 시스템과 운영 모델은 전제하지 않음.

## 0. 범위

| 구분 | 내용 |
|---|---|
| 보장 대상 | 모든 그림의 이미지 색인과 검색 |
| 보장하지 않는 대상 | 모든 미지의 그림에 대한 정확한 해석 |
| 이미지 임베딩의 역할 | 관련 그림 검색. 기하 정답, 정확한 치수, 방향, 연결의 원천이 아님 |
| 해석 범위 | 추출기와 검증 규칙을 갖춘 도면 유형 |
| 범위 밖 처리 | 원본 위치 반환, 답변 보류 |

## 1. v2 대비 수정 사항

| v2 가정 | v3 수정 |
|---|---|
| 이미지 임베딩으로 복잡한 그림을 이해 | 이미지 임베딩은 그림 검색에 사용. 기술적 정답은 원본 기하 정보, OCR, 관계 모델, 검증된 구조화 정보에서 획득 |
| 에지 밀도 기반 시각 토큰 배정 | 얇은 화살표, 단일 문자, 겹친 기호 등 희소하나 중요한 신호의 손실 위험. 탐지 중요도, 불확실성, 검증 실패 여부를 함께 사용 |
| 256차원 축소로 연산 감소 | 차원 축소는 벡터 저장과 유사도 계산량을 줄임. 인코더 추론 연산은 감소하지 않음 |
| 관계 모델 점수 0.91이면 확정 | 탐지 점수는 보정된 정답 확률이 아님. 도면 유형과 객체별 보정, 전역 정합성 검사, 기하 규칙 검증 후 확정, 후보, 기각으로 기록 |
| 모든 결과를 텍스트 LLM에 전달 | 질의 분류 후 식별자와 치수 조회는 데이터베이스로 직접 응답. 설명과 다문서 요약에 LLM 사용 |

## 2. 문서 등록 파이프라인

| 단계 | 처리 |
|---|---|
| 1. 입력 확인 | 파일 무결성, 접근 권한, 개정판, 형식 인식 |
| 2. 원본 구조 판정 | 벡터와 원본 정보 존재 여부로 처리 경로 선택 |
| 3-A. 원본 경로 | PDF 경로, 글리프, 좌표. SVG 개체. STEP 경계 표현(B-rep), 부품 구성표(BOM), 제품 제조 정보(PMI) |
| 3-B. 화소 경로 | 고해상도 타일 분할, 레이아웃과 도면 뷰와 기호 영역 분리, 도면 전용 OCR, 선과 원과 접점 추적, 기호와 관계 모델 |
| 4. 공통 중간 표현 | 경로와 무관하게 동일 스키마로 변환 |
| 5. 색인 생성(병렬) | 페이지, 영역, 세부 영역 시각 임베딩. 텍스트 BM25와 밀집 임베딩. 기호, 기하, 관계 그래프. 개정, 출처, 접근 권한 |
| 6. 품질 관리 | 개정판별 색인, 품질 확인, 불확실 항목 대기열 |

### 2.1 원본 형식별 처리 경로

| 원본 | 처리 |
|---|---|
| 텍스트 PDF, DOCX, XLSX | 텍스트, 행과 열, 수식 원본 파싱. OCR 미사용 |
| 벡터 PDF, SVG, DXF | 텍스트 좌표, 선, 곡선, 화살표, 폴리라인, 레이어, 선 스타일 우선 추출. 벡터 경로와 부품의 대응은 보장되지 않으므로 이웃, 접점, 선 스타일, 주석 규칙으로 의미 복원 |
| 래스터 도면, 스캔 | 판독 가능한 해상도로 영역 분할. OCR, 객체 탐지, 선분 검출(Hough 변환), 세선화, 접점 검출, 연결 요소 분석 병렬 수행. 단순 교차와 실제 접점 구분. 해상도에 따라 일부 좌표와 기하 관계는 확인 불가 |
| 3D CAD, STEP AP242 | 이미지 해석 없이 조립 계층, 형상, 속성, PMI 직접 파싱. CAD가 없는 경우 2D에서 3D를 복원하지 않음 |
| 사진, 인포그래픽 | 이미지 색인 대상. 사전 정의되지 않은 시각 의미는 추출 범위 밖으로 처리 |

### 2.2 도면 요소 추출

| 요소 | 방법 |
|---|---|
| 문자 | 기계도면 전용 OCR(eDOCr2, 치수와 기하공차 인식)과 Tesseract 비교. Ø, R, M, ± 등 공차 형식, 회전 문자, 단위의 별도 파서 |
| 표 | Docling, TableFormer로 머리글, 셀 관계, 병합 셀, 각주, 단위 유지 |
| 기하 | PDF와 SVG 경로 또는 OpenCV의 윤곽선, 선분, 원 검출. 문자, 화살표와 기하 요소 간 실제 연결 관계 추출 |
| 계통도, 회로도 | 관계 추출 트랜스포머(Relationformer, RelTR 계열)를 실험 후보로 사용. PID2Graph 외 도메인으로의 일반화는 보장되지 않음 |
| 기계도면 | 치수, 치수선, 치수 보조선, 형상, 도면 뷰의 다중 관계 추론. 근거 좌표와 함께 저장하고 오류 가능성이 있으면 보류 |

### 2.3 공통 중간 표현

| 구분 | 내용 |
|---|---|
| 공통 속성 | 문서 ID, 개정판, 적용 범위, 원본 위치, 쪽, 영역 좌표, 원본 형식, 파서 버전, 원본 값, 정규화 값, 검증 상태, 보안 등급 |

## 3. 시각 임베딩과 검색

### 3.1 1차 임베딩

| 항목 | 내용 |
|---|---|
| 기본 후보 | 2026년 공개 오픈 가중치 멀티모달 임베딩 모델. 텍스트와 이미지 구성 약 4억 4천만 매개변수, 768차원, 512와 256차원 축소 가능. 음성 인코더 미적재 |
| 비교 후보 | SigLIP 2(base, 약 8,600만 매개변수 이미지 인코더) |
| 색인 구조 | 페이지, 도면 뷰, 세부 영역의 계층 색인. 상하위 ID, 원본 좌표, OCR과 관계 그래프 참조 연결 |
| 결합 방식 | 텍스트와 이미지 독립 임베딩과 이미지와 캡션 결합 임베딩 비교 실험 |
| 식별자 검색 | 임베딩 유사도 단독 사용 금지. ID 완전 일치 조회, BM25와 병행 |
| 운용 조건 | 모델 권장 정밀도(bfloat16 또는 float32) 준수. 차원 축소 후 L2 재정규화. 질의와 문서의 동일 차원 사용. 검색 작업 접두어 준수 |

### 3.2 정밀 검색

| 항목 | 내용 |
|---|---|
| 방법 | 패치 단위 지연 상호작용(ColPali의 MaxSim) |
| 후보 모델 | ColSmol 256M, 500M. Qwen 기반 모델(ColQwen)은 미채택 |
| 적용 범위 | 상위 페이지와 영역에 한정. 패치 벡터 전량을 메모리에 상주시키지 않음 |
| 실험 | 토큰 풀링, 고정 예산 후보 생성 |

이미지 임베딩은 검색 점수용 표현이며 도면 수치와 위상의 정답 원천이 아님.

## 4. 질의 처리

| 단계 | 처리 |
|---|---|
| 1. 질의 분석 | 식별자와 의도 분류. 규칙 우선, 판별이 어려운 질의는 로컬 텍스트 LLM |
| 2. 필터 | 문서 접근 권한, 개정판, 제품 적용 범위 |
| 3. 검색 | SQL 완전 일치 조회, BM25, 텍스트와 시각 밀집 검색을 질의 유형에 따라 병렬 수행 |
| 4. 결합 | 상호 순위 융합(RRF). 상위 후보의 패치 단위 재검색 |
| 5. 관계 확장 | 후보 영역에 한정한 관계 그래프 확장. 질문 관련 수치와 도형 검증 |
| 6. 근거 묶음 | 판독 값, 출처, 원문 좌표, 미확인 사항 |
| 7. 응답 | 정형 사실 질의는 SQL과 규칙 결과로 응답. 서술형 질의는 기존 텍스트 LLM. 불확실 시 보류하고 원본 제시 |

크기, 거리, 각도는 도면에 명시된 치수와 축척 또는 CAD 원본 기하와 연결될 때 확정함. 화소 길이의 실제 길이 환산과 끊어진 선의 임의 연결은 금지함.

## 5. 모델 선택과 GPU 효율

| 방안 | 내용 |
|---|---|
| 원본 우선 | 원본 직접 추출과 규칙은 CPU 처리. 추출 불가한 화소 영역에 한정해 OCR과 탐지 실행 |
| 등록 시점 처리 | 시각 임베딩은 최초 등록과 변경 시 일괄 생성 |
| 증분 처리 | 문서와 영역 해시, 파서 버전 기준 |
| 시각 토큰 배정 | 문자와 기호 검출량, 얇은 선과 화살표 보호, 모델 불확실성, 질의 빈도, 오류 민감도 종합 |
| 차원 축소 | 256, 512차원은 색인 저장과 유사도 계산 절감. 인코더 연산은 동일 |
| 정밀 재검색 | 지연 상호작용 후보 10~50개로 제한. 구체적 값은 평가로 조정 |

| 산정 항목 | 값 | 비고 |
|---|---|---|
| 벡터 10만 개, 256차원, FP16 | 약 51.2MB | 벡터 데이터 기준. 색인과 메타데이터 제외 |
| 벡터 10만 개, 768차원, FP16 | 약 153.6MB | 동일 |
| 임베딩 모델 가중치(4억 4천만, BF16) | 약 0.88GB | 활성값, 문맥, 프레임워크 메모리 별도 |
| 동일 모델 가중치(FP32, CPU) | 약 1.76GB | 동일 |

가중치 크기를 실제 VRAM과 RAM 요구량으로 간주하지 않음. 양자화, 모델 교체, 병렬 처리에 따른 처리량은 실측함. CPU 실행 가능 여부와 처리 성능의 충분성은 별개임.

## 6. 폐쇄망, 온프레미스, 엣지

| 환경 | 구성 |
|---|---|
| 온프레미스 | 문서 파싱과 이미지 처리 배치 서버, 색인과 데이터베이스, 기존 LLM, 접근 권한과 결과 감사 로그 |
| 폐쇄망 | 가중치와 라이브러리 사전 반입, 해시 검증, 승인된 내부 저장소, 외부 호출과 자동 다운로드 차단. Docling은 사전 다운로드 경로(artifacts_path) 기반 오프라인 실행 지원 |
| 엣지 | 장비 성능에 따라 영역 분리, 경량 OCR, 소규모 캐시와 검색. 관계 모델, 지연 상호작용 모델, LLM의 동시 탑재는 장비별 실측 전 보장하지 않음 |

접근 통제는 검색 전에 적용함. 추출 메타데이터, 임베딩, 검색 색인도 민감 자료로 취급하며 삭제, 개정, 권한 변경 시 색인을 갱신함.

| 구성 요소 | 라이선스 확인 결과 |
|---|---|
| eDOCr2 | MIT |
| 1차 임베딩 후보, SigLIP 2 | Apache 2.0 |
| DTRT 공식 구현 | LICENSE 파일과 학습 가중치 미공개 |

모델, 데이터, 의존성 라이선스는 각각 별도 확인함.

## 7. 검증과 실험 설계

### 7.1 절제 실험

| 실험 | 구성 | 확인 사항 |
|---|---|---|
| A | OCR과 고정 길이 분할 텍스트 RAG | 기준선 |
| B | A와 페이지 단위 이미지 임베딩 | 시각 검색의 추가 효과 |
| C | B와 영역, 세부 영역 다중 해상도 | 작은 기호와 치수의 검색 개선 |
| D | C와 원본 벡터 우선 경로 | 기하 정보 정확도와 처리 시간 |
| E | D와 도면 전용 OCR, 관계 모델 | 개체와 위상 관계 정답률 |
| F | E와 근거 검증, 보류 | 잘못된 확정 답변 감소 |
| G | F와 상위 후보 지연 상호작용 | 검색 비용과 성능의 균형 |

모든 실험은 동일 문서, 질문, 텍스트 LLM으로 비교함. 원본 도면과 부품군 단위로 학습과 평가를 분리해 이미지 중복과 개정본 누출을 방지함.

| 색인 포괄성 | 대상 그림 중 이미지 색인 포함 비율 |
| 검색 | Recall@5, MRR, nDCG@10, 영역 적중률, 근거 좌표 IoU |
| 문자와 치수 | OCR 문자 오류율(CER), Ø, ±, 기하공차 완전 일치율, 단위와 부품번호 정확도 |
| 구조 | 객체 mAP, 연결 관계 정밀도, 재현율, F1, 접점과 단순 교차 오판, 오탐 관계 |
| 질의응답 | 정답률, 근거 일치율, 무근거 확정 답변 비율, 보류율, 위험과 응답 범위 곡선 |
| 자원 | 문서당 CPU 시간, 쪽당 GPU 시간, 최대 VRAM, 검색 지연(p50, p95), 쪽당 색인 크기, 질의 토큰 수 |

신뢰도 점수를 확률로 간주하지 않음. 클래스와 스캔 품질별 보정과 선택적 예측(selective prediction)으로 검증된 범위에 한해 자동 확정함.

## 8. 구현 우선순위

| 단계 | 내용 | 주장 범위 |
|---|---|---|
| P0 | Docling 직접 파싱과 표, 이미지 영역 분리, 시각과 텍스트 임베딩, BM25와 FAISS, 원본 영역 연결, 문서 개정과 접근 권한 | 검색 가능성 검증. 도면 의미 해석은 주장하지 않음 |
| P1 | eDOCr2 OCR, 문자와 치수, 선, 화살표 관계 복원, 원본 벡터 경로, 관계 스키마, 규칙 기반 검증 | 기계도면 유형별 적용 범위와 오답 통제 |
| P2 | 관계 추출 트랜스포머 실험, PID2Graph, 지연 상호작용 재검색, 차트 구조 추출, 현장 데이터 도메인 적응 | 계통도와 복합 이미지 확장 |

미해석 그림은 원본과 함께 반환함. 생성형 VLM 보조 경로는 두지 않음.

## 9. 정의

기술문서의 모든 이미지를 멀티모달 임베딩으로 색인하고 원본 벡터와 기하 데이터, 도면 전용 인식과 관계 모델로 검증 가능한 시각 정보를 별도의 근거 그래프로 보존함. 질의 시 정확한 정보 조회, 시각 유사도 검색, 관계 기반 검색을 결합하고 기존 텍스트 LLM에는 검증된 사실을 전달함. 원본 해석이 불충분한 경우 근거 이미지를 제시하고 판단을 보류함.

"모든 그림의 검색 가능성"은 구현 목표로 설정함. "모든 미지의 그림을 VLM 없이 완벽히 이해"는 공개 연구로 보장되지 않음. 지원 도면 유형과 허용 오차율, 보류율을 우선 정의함.
