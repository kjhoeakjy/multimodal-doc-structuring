# 이전 구상안

현행은 상위 폴더의 최신 버전. 아래는 대체된 안으로 검토 이력 보존 목적.

| 버전 | 요지 | 대체 사유 |
|---|---|---|
| v1~v3 | 개정과 적용 조건 검증 그래프, 공통 정보 단위 | 특정 업무에 치우침, 주제와 거리 |
| v4 초안, v4 수정안 | 전처리와 구조화 두 축, 선택적 전처리와 의미 관계 구조화 | 축 재편 |
| v5 초안 | 두 축 재편, 환경 등급과 압축 실측 | GPU 환경을 독립 축으로 둔 점. 기술 검토 노트로 보존 |
| v6 확정안 | 선택적 전처리와 의미 관계 구조화 | 사례와 제목 수정 |
| v7 | 표와 이미지의 구조와 적용 조건 보존 | 핵심을 분산 정보의 관계 연결로 좁힘 |
| v8 | 그림, 표, 각주에 분산된 정보의 관계와 적용 조건 연결 | 차별점과 근거 보강 |
| v9 | 차별점 네 가지와 2025~2026 근거, 조건 일치 전달 | 표현 정리와 사례 교체 |
| [v10](v10-적용-조건-보존-전처리-구조화.md) | 체결 토크 사례, 전체 기본 추출과 관계 점검 기준 추가 분석 | v11로 대체 |
| v11 | 주요 학회 논문 중심 재편. 적용 범위 상속, 참조 완결성 점검, 범위 일치 전달 | 오류 유형별 규칙 나열이 복잡해짐. 재구성 검증 하나로 표현 수준을 정하는 v12로 일반화 |
