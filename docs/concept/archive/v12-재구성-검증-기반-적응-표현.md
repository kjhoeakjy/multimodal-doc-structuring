# v12 재구성 검증 기반 적응 표현: 로컬 LLM을 위한 기술문서 전처리 및 구조화 방안

작성 2026-10-29. v11까지의 오류 유형별 규칙 나열을 버리고 영역마다 표현 수준을 하나의 기준(재구성 오차)과 연산 예산으로 결정하는 일반 구조로 다시 세운 안.

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**과제 정의** 문서의 각 영역을 로컬 LLM이 쓸 수 있는 가장 싼 표현으로 바꾸되 정보 손실이 없어야 함. 페이지 이미지를 그대로 넣는 방식은 질의마다 시각 토큰이 수천 개 들고 전부 텍스트로 바꾸는 방식은 변환에서 머리글과 값의 관계, 기호, 위치가 사라짐. 두 극단 사이에서 영역별로 어느 수준의 표현을 쓸지 정하는 기준이 지금까지 없었음.

**핵심 아이디어** 영역마다 싼 표현에서 비싼 표현 순으로 변환하고 변환 결과로 그 영역을 다시 그려 원본과 비교하는 재구성 검증 하나로 손실 여부를 판정함. 검증을 통과한 가장 싼 표현을 채택하고 통과하지 못한 영역에 한해 연산 예산 안에서 다음 수준으로 올림. 모든 값은 레이아웃 트리의 경로를 붙인 문장으로 저장해 질문에 맞는 문장에 한해 LLM에 전달함.

**적용 대상** PDF와 스캔 형태의 기술문서(정비 지침, 도면, 규격, 부품 목록). CAD 모델과 구조화된 설계 데이터는 제외함.

**설계 전제** 독립 실행 가능한 오픈소스 모델 활용. 제한된 연산 자원을 고려한 처리. 특정 조직의 시스템과 자원 현황은 전제하지 않음.

## 1. 문제

| 접근 | 비용 | 손실 | 한계 |
|---|---|---|---|
| 페이지 이미지 직접 입력(ColPali, VisRAG, ICLR 2025) | 질의마다 시각 처리, 쪽당 수천 토큰 | 없음 | 제한된 GPU에서 운용 어려움. 조건 연결을 모델 판단에 맡김 |
| 전부 텍스트 변환(Docling, Nougat) | 등록 시 1회 | 변환 오류가 그대로 LLM에 들어감 | 어느 영역이 틀렸는지 알 수 없음 |
| 오류 유형별 규칙 점검(v11) | 낮음 | 목록에 없는 오류 | 문서 유형마다 규칙 추가. 구조가 복잡해짐 |

필요한 것은 "이 영역의 이 표현이 충분한가"를 오류 유형과 무관하게 판정하는 기준 하나임.

## 2. 방법

### 2.1 표현 수준

| 수준 | 표현 | 변환 수단 | 비용 | 적용 영역 |
|---|---|---|---|---|
| 0 | 텍스트 층 직접 읽기 | PDF 파서(글자, 좌표, 벡터 도형) | CPU, 쪽당 0.2초 | 디지털 PDF |
| 1 | OCR 텍스트 | 기본 OCR, 선과 도형 검출 | CPU, 쪽당 수 초 | 스캔 이미지 |
| 2 | 구조화 텍스트 | 레이아웃 모델(DocLayNet 계열), 표 구조 모델(TableFormer 계열), 차트 변환(DePlot) | CPU 또는 소형 GPU | 표, 차트, 목록 |
| 3 | 소형 문서 시각언어모델(VLM) 전사 | 영역 한정 전사 | GPU, 영역당 수십 초 | 수준 2까지 실패한 영역 |
| 4 | 이미지 조각 자체 | 저해상도 조각을 질의 시 VLM 입력 | 질의마다 시각 토큰 | 다시 그릴 수 없는 영역(사진, 복잡한 도면 내용) |

### 2.2 재구성 검증

영역 R의 표현 r에 대해 r을 다시 그린 이미지 render(r)와 원본 image(R)를 비교함. 오차는 두 성분임.

| 성분 | 정의 | 잡는 오류 |
|---|---|---|
| 미설명 잉크 | 원본에는 있으나 render(r)에 없는 잉크 비율 | 누락(각주 줄, 기호, 라벨, 행) |
| 불일치 잉크 | render(r)에는 있으나 원본과 모양이 다른 잉크 비율(글자 단위 대조) | 오판독(48을 43), 구조 손실(칸 밀림, 머리글 병합 오류) |

오차가 임계값 이하이면 표현을 채택함. 비교는 이진화와 연결 성분 대조의 CPU 이미지 연산이며 정답 데이터가 필요 없음. 원본 자체가 기준이므로 각주 기호 누락, 공차 기호 누락, 숫자 오판독, 표 구조 손실, 그림 라벨 누락이 모두 같은 신호로 잡힘. 글자, 선, 표 격자, 기호는 다시 그릴 수 있고 사진과 도면의 기하 내용은 다시 그릴 수 없으므로 후자는 수준 4로 둠.

### 2.3 예산 내 수준 상승

1. 모든 영역을 가능한 가장 낮은 수준으로 변환하고 재구성 오차를 계산함
2. 오차가 임계값을 넘는 영역을 오차가 큰 순으로 정렬함
3. 문서당 연산 예산(시각 모델 호출 수 또는 초) 안에서 순서대로 한 수준씩 올리고 다시 검증함
4. 예산이 끝나면 남은 영역은 수준 4(이미지 조각)로 두거나 검토 필요로 표시함

GPU는 검증에 실패한 영역의 상위 수준에 한해 쓰이고 예산 하나로 정확도와 연산의 균형을 조절함. 과탐지로 호출이 폭증하는 문제가 구조적으로 막힘.

### 2.4 경로 직렬화

채택된 표현에서 값마다 레이아웃 트리의 조상 경로(문서, 절, 표 제목과 주의문, 머리글 묶음, 하위 머리글, 행, 셀, 각주)를 붙여 독립 문장 하나로 저장함. 도면은 표제란, 일반 주기, 뷰, 개별 표기 순이며 그림은 포함 관계 순임. 검색 단위를 독립 명제로 두면 검색과 질의응답이 좋아진다는 연구(Dense X Retrieval, EMNLP 2024)를 표, 그림, 도면으로 확장한 형태이며 v11의 적용 범위 상속은 이 경로의 특수한 경우임. 문장은 LLM 없이 구조 정보로 조립함.

### 2.5 질의 시 전달

질문의 대상, 속성, 조건과 문장의 경로를 대조해 일치하는 문장과 출처를 전달함. 조건이 없으면 경로가 다른 값을 병기하고 기록에 없는 조건이면 범위를 밝히고 보류함. 수준 4로 남은 영역이 질문에 필요하면 그 조각에 한해 저해상도 이미지를 함께 입력함. 수치는 LLM이 생성하지 않고 저장값을 그대로 전달함.

## 3. 기존 연구와의 관계

| 연구 | 학회 | 가져오는 것 | 차이 |
|---|---|---|---|
| DocLayNet, TableFormer, DePlot, Donut | KDD 2022, CVPR 2022, Findings of ACL 2023, ECCV 2022 | 수준 2와 3의 변환기 | 변환기 자체. 어느 수준을 쓸지 정하는 기준 없음 |
| Dense X Retrieval | EMNLP 2024 | 독립 명제 단위 저장 | 일반 텍스트 대상. 레이아웃 경로 없음 |
| Self-RAG | ICLR 2024 | 결과를 점검해 필요할 때 추가 처리 | 생성 단계의 학습된 판정. 본 방안은 변환 단계의 원본 대조 |
| Adaptive-RAG | NAACL 2024 | 난이도에 따른 처리 경로 선택 | 질문 단위. 본 방안은 영역 단위이며 기준이 원본 재구성 |
| ColPali, VisRAG | ICLR 2025 | 비교 대상 | 모든 영역을 수준 4로 두는 경우에 해당 |
| 순환 일관성(CycleGAN) | ICCV 2017 | 변환 결과를 되돌려 원본과 대조하는 원리 | 영상 변환 학습. 본 방안은 문서 표현 선택의 판정 기준으로 사용 |
| RaV-IDP | 2026 프리프린트 | 다시 그려 대조하는 추출 검증 | 단계적 표현 선택과 예산 없음. 실패 시 외부 상용 모델 사용 |

고유 기여는 재구성 오차를 문서 표현 선택의 단일 기준으로 두고 예산 안에서 수준을 올리는 구조와, 레이아웃 경로를 붙인 문장 저장의 결합임.

## 4. 사례

| 영역 | 수준 0 또는 1 결과 | 재구성 검증 | 조치 |
|---|---|---|---|
| FAA AC 43.13-1B 표 7-1 디지털 | 값 100개, 머리글, 주의문, 각주 | 통과 | 수준 0 채택, 경로 직렬화 |
| 같은 표 스캔본 | 각주 줄 누락 | 표 하단에 미설명 잉크 | 그 줄에 한해 수준 3 전사(22초) |
| NIST 도면 일반 주기 | 공차 값과 데이텀은 텍스트, 기호는 벡터 도형 | 기호 위치에 미설명 잉크 | 벡터 객체 해석으로 수준 0 안에서 복구 |
| 조립도 그림 | 상자 라벨과 번호는 텍스트 | 선과 상자는 다시 그려 통과, 번호 1과 7 미판독은 불일치 | 번호 원에 한해 수준 상승. 그림 자체는 포함 관계로 직렬화 |
| 결함 사진 | 텍스트 없음 | 다시 그릴 수 없음 | 수준 4. 질문 시 조각 입력 |

경로 직렬화 예: "FAA AC 43.13-1B 표 7-1, 무유 카드뮴 도금 나사산 기준, 설치 권장값, 인장형 너트, 세목 계열, 1/4-28, 50~70 in-lb, 추정값 표시 없음".

## 5. 검증

### 5.1 데이터

공개 원본 두 종(FAA AC 43.13-1B 7장, NIST 제품 제조 정보 시험 도면)과 합성 문서(체결 토크, 구역 점검). 각 문서에 디지털 원본과 스캔 변형을 둠. v11과 같은 데이터와 질의를 사용함.

### 5.2 비교와 지표

| 구분 | 비교 대상 | 지표 |
|---|---|---|
| 표현 선택 | 전부 최저 수준(검증 없음), 전부 최고 수준(전체 VLM 전사), 페이지 이미지 직접 입력, 제안 | 영역별 채택 수준 분포, 시각 모델 호출 수와 GPU 시간, 추출 정확도 |
| 재구성 검증 | 오류 유형 규칙 점검(v11) | 실제 오류(누락, 오판독, 구조 손실)에 대한 탐지 정밀도와 재현율, 오류 유형별 재현율 |
| 질의응답 | 텍스트 분할 검색, Docling 검색, 페이지 전체 입력, 페이지 이미지 입력, 제안 | 정답률, 조건 혼동 오답률, 적절한 보류 비율, 질의당 입력 토큰 |
| 예산 | 예산을 바꿔 가며 | 정확도 대 연산 곡선 |

### 5.3 v11까지의 실측(같은 데이터, 재사용)

| 항목 | 결과 |
|---|---|
| 전처리 시간(1쪽, CPU) | 수준 0 0.2초, Docling 19초, 문서 VLM 전체 120초. NIST 도면 장당 1.1초, 5.9초, 103초 |
| 질의응답(로컬 LLM 3B) | FAA 디지털 20/20, 스캔 19/20, NIST 도면 13/14. 텍스트 분할, Docling, 문서 VLM 검색은 2, 2, 9 이하. 페이지 전체 입력 2/20, 4/20 |
| 합성 문서(규칙 판독, 376 질의) | 값 97%, 조건 90%, 그림 연결 86%, 조건 미지정 86%. 텍스트 기반 비교군은 그림 연결과 조건 미지정 0% |
| 영역 재처리 효과 | 스캔 구역 점검에서 값과 조건 연결 11/61에서 61/61. 과탐지 시 호출 654회로 폭증(예산 필요성의 근거) |

## 6. 1장 구성

제목: 재구성 검증으로 표현 수준을 정하는 기술문서 전처리 및 구조화

| 구성 | 내용 |
|---|---|
| 문제 | 이미지 직접 입력은 비싸고 텍스트 변환은 손실을 모름. 영역별 표현 선택 기준 부재 |
| 전처리 | 표현 수준 다섯 단계. 다시 그려 원본과 비교하는 검증 하나로 손실 판정. 예산 안에서 실패 영역에 한해 상승 |
| 구조화 | 값마다 레이아웃 경로를 붙인 문장. 질문과 일치하는 문장에 한해 전달, 범위 밖이면 보류 |
| 사례 | 토크 표 한 영역이 수준 0에서 통과하고 스캔본 각주 줄이 미설명 잉크로 잡혀 수준 3으로 오르는 도식 |
| 검증 | 공개 문서 실측. 채택 수준 분포, GPU 시간, 탐지 정밀도와 재현율, 정답률, 입력 토큰 |

## 7. 면접 대비

| 예상 질문 | 답변 요지 |
|---|---|
| 규칙 기반이 아닌가 | 판정 기준은 원본과의 재구성 오차 하나임. 오류 유형 목록이 없고 문서 유형이 바뀌어도 변환기 교체로 대응함 |
| 다시 그릴 수 없는 영역은 | 사진과 도면의 기하 내용은 수준 4로 두고 질문에 필요할 때 조각을 입력함. 텍스트로 안 되는 것을 억지로 텍스트화하지 않음 |
| 재구성 비교의 비용은 | 이진화와 연결 성분 대조의 CPU 연산. GPU는 실패 영역의 상위 수준에 한해 사용 |
| 선행 연구와의 차이 | 변환기는 학회 검증 모델을 그대로 씀. 더한 것은 표현 선택 기준과 예산 구조, 경로 직렬화 |
| 남는 오류는 | 원본과 같은 모양으로 틀리게 읽힌 경우. 표본 감사와 질문 시점의 근거 부재 신호로 보완 |
