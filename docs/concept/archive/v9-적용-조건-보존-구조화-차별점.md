# v9 표와 이미지에 분산된 정보의 관계와 적용 조건을 보존하는 전처리 및 구조화 방안

작성 2026-10-28. v8의 사례와 기술 구성을 유지하고 차별점과 근거, 처리 순서를 보완함. 적용 대상은 PDF와 스캔 형태의 기술문서.

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**핵심 아이디어** 그림, 표, 각주에 나뉘어 기록된 값과 적용 조건을 분리하지 않고 연결한 형태로 저장하고 질문의 조건에 맞는 값과 출처를 LLM에 전달함.

**적용 대상** PDF와 스캔 형태의 기술문서(교범, 시험 기준, 규격). CAD 모델과 구조화 설계 데이터는 대상에서 제외함.

**설계 전제** 독립 실행 가능한 오픈소스 모델 활용. 제한된 연산 자원을 고려한 효율적 처리. 특정 조직의 시스템이나 자원 현황을 전제하지 않음.

## 1. 문제

기술문서의 정보는 여러 위치와 형식에 나뉘어 기록됨. 부품의 위치는 그림에, 구역별 기준값은 표에, 적용 조건은 각주에 있는 경우가 있음. 텍스트 변환 과정에서 이 정보가 분리되면 값을 정확히 읽더라도 그 값이 어느 대상에 어떤 조건으로 적용되는지 확인할 수 없음. 문제는 글자를 정확히 읽는 데서 끝나지 않고 서로 다른 정보가 어떻게 연결되는지 파악하는 데 있음.

## 2. 해결 방안

### 2.1 데이터 전처리

처리 순서는 다음과 같음.

1. **1차 추출** 텍스트 레이어가 있는 문서와 디지털 표는 CPU 기반 파서로 텍스트, 셀, 위치를 추출함. PDF 도면은 벡터 객체와 좌표를 활용함. 스캔 문서와 이미지는 기본 OCR 또는 경량 시각 분석으로 요소와 위치를 확보함.
2. **연결 확인** 각주 표시, 참조 번호, 식별자처럼 연결이 예상되는 명시적 참조가 실제로 연결되는지 확인함.
3. **연결 누락 영역 재해석** 예상되는 연결이 없거나 상충하는 경우에 한해 해당 원본 영역에 소형 시각언어모델(VLM)을 적용함. 그림의 부품 라벨과 구역 경계 인식이 필요한 경우 해당 기능을 지원하는 모델을 선택함.
4. **저장** 대상, 속성 또는 관계, 값, 적용 조건, 출처로 저장하고 질의 시 재사용함.

| 명시적 참조 | 연결 누락 판단 기준 | 재해석 영역 |
|---|---|---|
| 표의 각주 기호 | 대응하는 각주 문장 없음 | 표 하단 영역 |
| 표의 구역명 | 구역 참조가 있는 문서에서 부품 라벨의 소속 구역 또는 도면의 구역 미확인 | 해당 도면 영역 |

연결 누락 재해석은 모든 추출 오류를 해결하는 방법이 아님. 명시적 참조가 있어 연결이 예상되는 경우에 적용하는 선택적 오류 복구 방식임. 1차 추출에서 완전히 누락된 객체는 탐지 대상이 아님. 검증 전의 추출값은 확정된 사실로 취급하지 않음.

목적: 필요한 정보를 적은 연산으로 확보함. 연산량 감소 여부는 재처리 비율과 탐지 비용에 따라 달라지므로 실험으로 검증함.

제한된 환경과의 관계: 1차 추출은 CPU 파서로 수행하고 GPU를 쓰는 시각 모델은 연결 누락 영역에 한정함.

### 2.2 데이터 구조화

**정보 구조** 대상, 속성 또는 관계, 값, 적용 조건, 출처로 저장함. 단위는 값과 함께 표기함. 출처는 이미지의 영역, 표의 셀, 각주 번호를 가리킴. 서로 다른 자료에서 추출한 정보가 잘못 연결된 경우 출처를 따라 원본으로 돌아가 확인함.

**표의 연결** 헤더, 셀, 각주의 관계는 문서 구조를 이용해 연결함.

**그림의 연결** 부품 라벨과 구역 경계를 추출한 뒤 포함 관계를 확인함. 공간적 근접을 근거로 포함 관계를 확정하지 않으며 경계가 불명확한 경우 연결을 확정하지 않고 원본과 함께 보존함.

**적용 조건의 저장** 각주, 구역, 문서 버전에 흩어진 조건을 값에 붙여 저장함. 같은 대상에 조건이 다른 값이 여럿 있으면 모두 보존함.

**질의 시 입력 구성** 질문의 대상과 조건에 맞는 값, 조건, 출처를 저장된 관계에서 조회해 전달함. 구역의 기준값을 부품 자체의 값으로 옮기지 않음.

목적: LLM이 문맥을 잘못 적용하지 않도록 필요한 관계와 출처를 제공함.

제한된 환경과의 관계: 구조화는 문서 등록 시점에 한 번 수행해 재사용하고 질의 시점에는 필요한 값과 조건에 한해 소형 로컬 LLM에 전달해 입력량을 줄임.

## 3. 사례

가상 기술문서 기준.

**원본 구성**

- 부품 배치도: 부품 A-17이 2구역 경계 안에 위치
- 구역별 기준 표

| 구역 | 최대 허용 온도 |
|---|---|
| 1구역 | 70°C |
| 2구역 | 80°C*, 95°C** |

\* 정상 운전 조건에서 적용
\** 비상 운전 시 60초 이내 적용

**질문** A-17이 설치된 구역에 적용되는 정상 운전 시 최대 허용 온도 기준

**필요 정보** 소속 구역(배치도), 구역의 값(표), 적용 조건(각주). 하나라도 빠지면 답변 불가.

**구조화 결과**

| 대상 | 속성 또는 관계 | 값 | 적용 조건 | 출처 |
|---|---|---|---|---|
| A-17 | 소속 구역 | 2구역 | 없음 | 부품 배치도의 A-17 라벨과 2구역 경계 |
| 2구역 | 구역별 최대 허용 온도 | 80°C | 정상 운전 | 구역별 기준 표의 2구역 행, 각주 |
| 2구역 | 구역별 최대 허용 온도 | 95°C | 비상 운전, 60초 이내 | 구역별 기준 표의 2구역 행, 각주 |

**질문별 전달 결과**

| 질문 | 전달 내용 |
|---|---|
| 정상 운전 시 기준 | 80°C, 정상 운전 조건, 출처 |
| 조건 미지정 | 80°C(정상 운전)와 95°C(비상 운전, 60초 이내) 병기 |
| 시험 조건 등 기록 없는 조건 | 해당 조건의 기준 없음. 답변에 필수적인 근거가 없으므로 답변 보류 |

**연결 누락 재해석 예시** 스캔본에서 각주 문장이 인식되지 않은 경우 표의 각주 기호가 연결되지 않은 참조로 확인됨. 표 하단 영역에 한해 VLM을 다시 적용해 조건을 확보함.

## 4. 차별점

일반적인 답안은 문서를 텍스트로 변환해 일정 길이로 나눈 뒤 검색하는 구성이거나 페이지 이미지를 그대로 검색하는 구성임. 개별 요소는 2026년 연구에 부분적으로 있으며 이를 기술문서의 그림, 표, 각주 연결에 맞춘 하나의 처리 흐름으로 구성한 점이 차별점임. 수치 근거는 논문 정독 노트와 출처 검증에 둠.

| 구분 | 일반적인 구성과 최신 연구 | 이 제안 |
|---|---|---|
| 적용 조건 | 각주와 조건은 본문 텍스트의 일부. 조건부 지식 연결은 의생명 분야 연구(Condition-Gated Reasoning, 2026)에 있음 | 값마다 적용 조건을 함께 저장. 항공 기술문서 표준 S1000D의 적용성 개념을 그 구조가 없는 PDF와 스캔 문서에 복원. 조건 미지정 질문에는 조건별 값 병기 |
| VLM 적용 범위 | 전체 페이지에 동일 처리. 최신 연구(ParseFixer, DEC, 2026)는 파싱 품질 기준으로 재처리 | 명시적 참조의 연결 누락을 기준으로 재처리 영역 결정 |
| 그림과 표의 연결 | VLM이 그림을 설명한 텍스트를 검색. 도면 연구(BLUEPRINT, 2026)는 영역 검색 목적 | 부품 라벨과 구역 경계를 추출한 뒤 식별자 일치와 포함 관계 확인으로 연결. 모델의 추론에 맡기지 않음 |
| LLM 입력 | 검색된 조각을 그대로 입력 | 질문의 조건과 저장된 적용 조건을 대조해 일치하는 값과 출처를 전달 |

## 5. 검증

모든 방식은 파싱 결과를 저장해 재사용하는 조건으로 비교함.

| 구분 | 비교 | 지표 |
|---|---|---|
| 전처리 | 전체 페이지 VLM 처리, 파싱 품질 기준 재처리, 연결 누락 영역에 한정한 VLM 처리 | 전처리 GPU 처리 시간 |
| 구조화 | 고정 길이 분할 문서의 검색 결과 입력, 관계 및 적용 조건을 연결한 정보 입력 | 관계 연결 정확도, 질의응답 정답률, 질의당 입력 토큰 수 |

관계 연결 정확도는 소속 구역, 적용 조건, 출처가 값에 올바르게 연결된 비율. 질의당 입력 토큰 수는 정답률과 함께 기재함. 측정 전이므로 수치는 기재하지 않음. 구조화로 정답률이 낮아지는 경우도 기록함.

## 6. 1장 구성

제목: 표와 이미지에 분산된 정보의 관계와 적용 조건을 보존하는 전처리 및 구조화 방안

| 구성 | 내용 |
|---|---|
| 문제 정의 | 그림, 표, 각주의 정보가 텍스트 변환 과정에서 서로 분리될 위험. 근거 한 줄: 요소 유형별로 우수한 파싱 도구가 다름(ParseBench, 2026) |
| 데이터 전처리 | 1차 추출, 명시적 참조의 연결 확인, 연결 누락 영역에 한해 소형 VLM 재해석. 각주 누락을 감지해 각주 영역을 재처리하는 사례 하나로 표시 |
| 데이터 구조화 | 대상, 속성 또는 관계, 값, 적용 조건, 출처의 연결. 적용 조건은 값과 함께 저장(S1000D 적용성 개념). 등록 시 1회 구조화, 질의 시 필요한 값과 조건에 한해 소형 로컬 LLM에 전달 |
| 사례 | 부품 배치도, 구역별 기준 표, 각주를 실제 형태로 제시하고 LLM 전달 과정까지 도식화. 질문 조건별 전달 결과는 한 줄 |
| 검증 | 관계 연결 정확도, 질의응답 정답률, 전처리 GPU 처리 시간, 질의당 입력 토큰 수 |

양자화, GPU 캐시, 모델별 성능 수치, 연구별 수치 비교표, 모델 후보, 하드웨어 사양, 저장소 설계, 근거 충분성 판정은 포함하지 않음. 모델명과 특정 내부 업무, 시스템은 언급하지 않음.

## 7. 면접 대비 답변 요지

- 래스터 도면의 경계 추출 신뢰도: 소형 문서 모델의 레이아웃 mAP는 0.27 수준(Granite-Docling 모델 카드). PDF 도면은 벡터 객체와 좌표를 우선하고 래스터 도면에서 실패하면 미확정으로 두고 사람 확인으로 넘김.
- 식별자 표기 불일치(A-17, A17, A-17-01): 문서별 표기 규칙을 정규화한 뒤 일치시키고 정규화로 해결되지 않으면 미확정.
- 문서 버전 혼재: 출처에 버전을 포함하고 구버전 표와 신버전 그림의 조합은 연결을 확정하지 않음.
- CPU 전용 환경: 소형 문서 모델도 CPU에서는 쪽당 수십 초 수준이라 대량 처리에 부적합. GPU 1장 수준 필요.
