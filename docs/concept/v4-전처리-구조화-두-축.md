# v4 전처리·구조화 두 축 구상안 (현행, 확정 대기)

작성 2026-10-28. v1~v3를 대체함.

## 1. 핵심 질문

폐쇄망·제한된 GPU 환경에서 공개 가중치 LLM에 비정형 데이터(표·이미지·기술문서)를 어떻게 입력할 것인가.

## 2. 핵심 답

질의 시점에 이미지와 문서 원본을 그대로 입력하지 않음. 적재 시점에 해석·검증해 두고 질의 시점에는 필요한 최소 정보를 입력함.

## 3. 축 1: 데이터 전처리

AI가 이해하기 유리한 입력으로 변환하는 단계.

| 항목 | 내용 |
|---|---|
| 형식 판별·경로 분기 | 디지털 텍스트·표·CAD 속성은 파서로 처리(GPU 미사용). 스캔본·도면·사진 영역은 양자화 소형 VLM으로 처리. GPU 사용 영역 최소화 |
| 이미지 유형별 변환 | 표 이미지는 행·열 구조, 도면 주석은 치수·공차 필드, 차트는 수치 표, 사진은 캡션·태그로 변환. 변환 불가 영역은 원본 영역 이미지로 보관 |
| 정규화 | 단위, 부품 번호 표기, 영문 원문 용어와 한국어 용어 병기 |
| 적재 시점 일괄 처리 | VLM 연산을 사용량이 적은 시간대로 이동. 질의 시점 GPU 부하 제거 |
| 재구성 대조 검증 | 변환 결과로 표·주석을 재구성해 원본과 대조. 불일치 영역에 한해 상위 모델 재해석, 이후 사람 검토. 정답 데이터·학습 불필요 |

## 4. 축 2: 데이터 구조화

AI가 짧은 입력으로 정확하게 읽을 수 있는 단위로 저장하는 단계.

| 항목 | 내용 |
|---|---|
| 자기완결 정보 단위 | 표 셀 하나에도 대상·속성·값·단위·적용 조건·헤더 경로·원문 위치·검증 상태를 포함. 검색된 단위 단독으로 해석 가능하므로 앞뒤 문맥 입력 불필요 |
| 계층 보존 | 문서·절·표·행 계층 유지. 검색 결과에 상위 제목 경로 자동 부착 |
| 세 가지 표현 | 동일 정보를 조회용 행(DB), 검색용 압축 서술문, 확인용 원본 영역으로 저장 |
| 입력 예산 기반 조립 | 정확한 값은 DB 조회 결과 1행. 설명 질의는 관련 정보 단위와 상위 맥락. 시각 판단이 필요한 경우에 한해 원본 영역 이미지 |

## 5. 제한된 연산 자원과의 연결

- 이미지 입력은 장당 많은 토큰을 차지함. 질의 시점 이미지 입력 제거로 입력 길이 축소.
- KV 캐시 메모리는 입력 길이와 동시 요청 수에 비례함. 입력 축소는 동일 GPU의 동시 처리량 증가로 연결됨.
- 전처리는 양자화 소형 모델 우선, 검증 실패 영역에 한해 상위 모델 호출.

## 6. 차별점

1. 이미지 해석을 질의 시점에서 적재 시점으로 이동.
2. 자기완결 정보 단위로 짧은 입력에서도 정확도 확보.
3. 재구성 대조 검증을 전제로 한 경량 모델 사용.

개별 기술(단계적 모델 호출, 렌더링 후 대조)은 기존 연구에 존재함. 질의 시점 연산 최소화를 기준으로 전처리·구조화를 설계한다는 점을 제안의 요지로 함.

## 7. 검증 지표(안)

| 지표 | 목적 |
|---|---|
| 구조·관계 추출 F1 | 표 헤더·셀, 이미지 객체·주석 관계 보존 |
| 원문 일치율 | 추출 정보와 원본의 일치 |
| 질의 정확도, 잘못된 근거 사용률 | 구조화 결과의 실제 활용 효과 |
| 질의당 입력 길이, 상위 모델 호출 비율 | 처리 효율 |
