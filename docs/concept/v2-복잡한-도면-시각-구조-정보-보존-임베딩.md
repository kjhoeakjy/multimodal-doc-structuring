# v2 복잡한 기술 도면의 시각 정보와 구조 정보 보존을 위한 적응형 전처리 및 임베딩

작성 2026-10-29. v1(문자, 표, CAD 속성 중심)이 복잡한 도면의 해석을 범위에서 제외한 한계를 보완한 안.

**주제** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**제목** 복잡한 기술 도면의 시각 정보와 구조 정보 보존을 위한 적응형 전처리 및 임베딩 시스템

**목표** 기술문서에 설계도면, 단면도, 회로도, 계통도, 그래프가 포함되어도 모든 그림을 검색 가능한 상태로 색인하고 그림 유형과 복잡도에 맞는 모델로 기술정보의 추출 범위와 검색 정확도를 최대화함.

**설계 전제** 생성형 시각언어모델(VLM) 미사용. 폐쇄망, 제한된 GPU, 기존 텍스트 LLM. 특정 조직의 시스템과 운영 모델은 전제하지 않음.

## 1. v1의 한계와 문제 재정의

v1은 디지털 PDF, OCR 문자, 표, CAD 원본 속성을 대상으로 함. 그림에서 문자를 추출하지 못하면 그 그림은 검색 대상에서 사라짐. 도면의 기하 관계와 연결 관계 해석은 범위에서 제외함.

| 구분 | 의미 | 필요 기술 |
|---|---|---|
| 시각 검색 | 그림 자체를 임베딩해 질문과 관련된 그림 검색 | 이미지와 텍스트의 공통 임베딩 모델 |
| 시각 이해 | 그림의 형상, 위치, 연결 관계, 치수, 기능적 의미 추출 | 도면 유형별 탐지, 인식, 관계 추출 모델 |

두 문제를 분리함. 임베딩은 원본의 압축 표현으로 세부 정보를 정확히 보존하거나 복원하지 못함. 원본 이미지, 좌표, 추출 정보를 별도로 유지함.

## 2. VLM을 쓰지 않는 근거

| 근거 | 내용 |
|---|---|
| 환각 | 생성형 모델은 원본에 없는 값을 생성함. 2D 기계도면 주석 추출 연구(Khan 외, 2025)에서 미세조정한 Donut의 환각률 10.8%, Florence-2 21.6% |
| 검증 가능성 | 탐지, 인식, 관계 추출 모델은 출력마다 좌표와 신뢰도가 있어 원본 대조가 가능함 |
| 비용 | 생성은 토큰 단위 반복 연산. 임베딩과 탐지는 영역당 1회 연산 |
| 역할 분리 | 기존 텍스트 LLM에 이미지 입력 기능이 불필요함. 그림 정보는 구조화 데이터와 원본 영역으로 전달 |

해석 모델의 범위 밖에 있는 그림도 시각 임베딩으로 검색되고 원본 영역이 근거로 제시됨. 해석하지 못한 정보를 생성으로 채우지 않음.

## 3. 전체 구조

| 단계 | 처리 | 산출물 |
|---|---|---|
| 1. 문서 분해 | 페이지, 그림, 표, 주석, 도면 뷰, 세부 영역 검출. 원본 해상도와 좌표 유지 | 계층형 영역 목록 |
| 2-A. 시각 임베딩 | 페이지, 영역, 세부 영역 이미지를 공통 임베딩 공간에 사상 | 시각 벡터 |
| 2-B. 구조 추출 | 그림 유형별 전문 모델로 기호, 문자, 연결선, 치수, 표 구조 추출 | 개체와 관계, 출처 좌표 |
| 3. 통합 색인 | 시각 벡터, 텍스트 벡터, 구조화 데이터, 원본 이미지 연결 | 4종 색인 |
| 4. 검색 | 질의 유형별 색인 조합, 상위 후보의 정밀 재검색 | 근거 묶음 |
| 5. 답변 | 기존 텍스트 LLM이 구조화 사실과 출처로 답변. 원본 영역 함께 제시 | 답변, 근거 영역 |

2-A는 모든 그림을 빠짐없이 검색 가능하게 만드는 계층이고 2-B는 그림의 기술적 의미를 구조화하는 계층임. 두 계층을 분리해 해석 실패가 검색 실패로 이어지지 않게 하고 전처리 비용을 계층별로 조절함.

## 4. 시각 임베딩

### 4.1 임베딩 모델

텍스트와 이미지를 하나의 벡터 공간에 임베딩하는 경량 멀티모달 임베딩 모델을 사용함. 비생성형 인코더로 이미지 설명문 생성 없이 질문과 이미지의 유사도를 계산함.

| 요구 조건 | 내용 |
|---|---|
| 규모 | 텍스트와 이미지 구성 10억 매개변수 이하. CPU와 엣지 장비 실행 가능 |
| 출력 차원 | 차원 축소(Matryoshka) 지원. 1차 검색용 저차원과 재검색용 고차원 병행 |
| 시각 토큰 | 이미지당 시각 토큰 예산 조절 가능 |
| 라이선스 | 상업적 사용과 오프라인 실행 허용 |

후보 모델은 2026년 공개된 오픈 가중치 멀티모달 임베딩 모델(텍스트와 이미지 구성 약 4억 4천만 매개변수, 768차원, 시각 토큰 70~1,120 조절)과 SigLIP 2임. 공개 벤치마크 수치이며 기술 도면에서의 성능은 실측 대상임.

### 4.2 다중 해상도 색인

고해상도 도면 한 장에 정면도, 측면도, 단면도, 상세도, 치수표, 주석이 함께 있음. 축소한 페이지 하나를 임베딩하면 작은 치수와 기호가 구별되지 않음.

| 단위 | 대상 | 역할 |
|---|---|---|
| 페이지 | 전체 페이지 | 질문과 관련된 문서와 쪽 검색 |
| 영역 | 도면 뷰, 그림, 표 | 관련 그림 검색 |
| 세부 | 기호, 치수, 주석, 부분 형상 | 작은 시각 요소 검색 |

각 임베딩에 원본 좌표와 상위 단위를 연결함. 세부 영역이 검색되면 상위 영역과 페이지로 문맥을 추적함. 세부 영역은 주변 문맥 손실을 막기 위해 일정 비율 중첩해 분할함.

### 4.3 영역 복잡도에 따른 시각 토큰 배정

시각 토큰 예산이 커질수록 연산량이 증가함. 모든 영역에 같은 예산을 쓰지 않고 영역의 시각 복잡도로 예산을 배정함.

| 복잡도 측정 | 계산 | 비용 |
|---|---|---|
| 잉크 밀도 | 이진화 후 전경 화소 비율 | 화소 연산 |
| 에지 밀도 | 에지 검출 후 에지 화소 비율 | 화소 연산 |
| 소형 요소 수 | 연결 요소 중 일정 크기 이하의 개수 | 화소 연산 |

복잡도 하위 구간 70~140토큰, 중간 280토큰, 상위 560~1,120토큰. 구간 경계는 검색 성능과 처리 시간의 실측으로 결정함. 단순 영역의 예산을 줄여 확보한 연산을 복잡한 도면에 배정함.

## 5. 구조 추출

### 5.1 그림 유형 분류

영역 검출 후 그림 유형을 분류함. 유형 분류는 시각 임베딩과 유형 설명문의 유사도 또는 소형 분류기로 수행해 추가 모델 실행을 최소화함.

### 5.2 유형별 추출 모델

| 그림 유형 | 모델과 기술 | 추출 정보 |
|---|---|---|
| 기계 설계도면 | 회전 경계 상자 탐지(YOLO-OBB), OCR, 치수선과 지시선의 연결 규칙 | 치수, 공차, 주석, 형상 참조 |
| 계통도, 회로도, 배선도 | 기호 탐지와 연결선 관계 추출 트랜스포머(Relationformer 계열) | 구성요소, 연결, 방향 |
| 표, 부품 명세 | TableFormer, Table Transformer | 행, 열, 셀, 머리글 관계 |
| 그래프, 차트 | 축, 범례, 데이터 요소 탐지와 OCR, 축 눈금 기반 좌표 변환 | 축 단위, 계열, 수치 |
| 3D CAD | STEP 파서(Open CASCADE Technology) | 부품 계층, 형상과 속성, PMI |
| 사진, 복합 삽화 | 객체 탐지 | 객체 종류와 위치 |

모든 모델은 비생성형임. 출력마다 좌표와 신뢰도를 가지며 기준 미달 값은 확정하지 않고 보류함.

### 5.3 관계 추출의 근거 연구

| 연구 | 방법 | 의의 |
|---|---|---|
| DTRT(Bai 외, CVPR 2026) | 공학 도면의 기호와 선을 검출하는 데 그치지 않고 구성요소 간 관계를 직접 예측해 그래프 생성. 중요도가 낮은 이미지 토큰을 동적으로 축소 | 관계 구조화와 고해상도 처리 효율을 함께 다룸. P&ID R@1000 94.84%, 전기 회로도 R@200 92.52% |
| Stürmer 외(DSAA 2025) | Relationformer 기반으로 P&ID의 기호와 연결을 한 모델로 추출 | 모듈형 기준선 대비 연결 탐지 정확도 25% 이상 향상. 실제 도면 기반 공개 벤치마크 |

DTRT는 공개 코드가 확인되지 않아 방법론 근거로 사용하고 구현은 공개 모델과 데이터로 재현 가능한 Relationformer 계열로 함. 두 연구 모두 P&ID와 전기 회로도 대상이며 항공기 기계도면 전반의 일반화 결과는 아님.

## 6. 통합 색인과 LLM 전달

### 6.1 구조화 결과(가상 예시)

```json
{
  "figure_id": "FIG-023",
  "figure_type": "계통도",
  "entities": [
    {"id": "A", "type": "밸브", "bbox": [312, 401, 356, 445], "score": 0.97},
    {"id": "B", "type": "펌프", "bbox": [610, 388, 690, 468], "score": 0.95}
  ],
  "relations": [
    {"subject": "A", "predicate": "연결", "object": "B", "score": 0.91, "status": "확정"}
  ],
  "source": {"document": "TECH-001", "revision": "C", "page": 12, "region": [120, 250, 850, 700]}
}
```

### 6.2 색인

| 색인 | 저장 내용 | 대응 질문 |
|---|---|---|
| 시각 색인 | 페이지, 영역, 세부 영역의 이미지 임베딩 | "이러한 구조가 있는 도면" |
| 텍스트 색인 | OCR 문자, 캡션, 구조화 결과의 텍스트 임베딩과 BM25 | "펌프와 연결된 밸브 관련 자료" |
| 관계 테이블 | 개체와 관계, 신뢰도, 좌표 | "밸브 A와 펌프 B의 연결 여부" |
| 메타데이터 | 문서번호, 도면번호, 개정판, 접근 권한 | "TECH-001 12쪽 도면" |

### 6.3 LLM 전달

기존 텍스트 LLM에는 확정된 개체와 관계, 출처, 보류 항목 목록을 텍스트로 전달함. 이미지는 LLM에 입력하지 않고 답변과 함께 원본 영역으로 사용자에게 제시함. 질문이 해석 범위 밖의 그림에 해당하면 관련 그림의 위치를 제시하고 해석 결과는 생성하지 않음.

v1의 문서 개정 관리, 출처 추적, 식별자 정규화, 규격과 근거의 분리는 그대로 유지하고 그림 정보까지 확장함.

## 7. GPU 효율성

| 방안 | 내용 |
|---|---|
| 경량 임베딩 | 10억 매개변수 이하의 멀티모달 임베딩 모델 |
| 차원 단계화 | 1차 검색 256차원, 재검색 768차원. 256차원은 768차원 대비 저장 공간 3분의 1 |
| 시각 토큰 배정 | 영역 복잡도에 따른 예산 배정(4.3절) |
| 조건부 구조 추출 | 그림 유형에 해당하는 추출 모델에 한정해 실행 |
| 등록 시점 처리 | 임베딩과 구조 추출은 문서 등록과 변경 시 1회 수행 |
| 증분 처리 | 변경된 문서와 그림을 재처리 |
| 2단계 검색 | 단일 벡터로 후보 검색 후 상위 후보에 다중 벡터 정밀 재검색 |

### 정밀 재검색

ColPali(ICLR 2025)는 페이지를 하나의 벡터로 압축하지 않고 이미지 패치별 임베딩을 보존해 질문과 패치의 유사도를 합산함. 세밀한 영역 비교에 유리하나 페이지당 다수 벡터로 저장과 검색 비용이 큼. 1차로 경량 임베딩 모델의 단일 벡터 검색을 수행하고 상위 후보에 한해 다중 벡터 재검색 또는 세부 영역 재검색을 적용함. 기술 도면에서의 품질 유지 여부는 실측 대상임.

## 8. 실험 설계

### 8.1 비교 구성

| 실험 | 구성 | 검증 목적 |
|---|---|---|
| A | OCR 텍스트와 텍스트 RAG(v1) | 기준선 |
| B | A와 그림 단위 시각 임베딩 | 이미지 직접 임베딩의 효과 |
| C | B와 다중 해상도 색인 | 세부 시각 요소 검색 개선 |
| D | C와 복잡도 기반 시각 토큰 배정 | 동일 연산 대비 검색 성능 |
| E | D와 유형별 구조 추출 | 관계 질문 정답률 |

### 8.2 지표

| 대상 | 지표 |
|---|---|
| 그림 검색 | 관련 도면과 그림의 Recall@5 |
| 영역 검색 | 정답 포함 세부 영역의 검색률 |
| 문자 추출 | 치수, 기호, 부품번호 정확도 |
| 관계 추출 | 구성요소와 연결 관계 F1 |
| 복합 질문 | 여러 그림과 문서를 함께 쓰는 질문의 정답률 |
| 근거 | 답변과 원본 영역의 일치율, 보류 비율 |
| 효율 | 문서당 처리 시간, GPU 메모리와 사용 시간, 색인 크기 |

### 8.3 데이터

| 데이터 | 용도 |
|---|---|
| DesignQA(Autodesk Research) | 기술 규정, CAD 이미지, 공학 도면 결합 질의응답 |
| ViDoRe | 문서 이미지 검색 일반 성능 |
| Stürmer 외 P&ID 벤치마크 | 계통도 관계 추출 |
| NIST PMI 시험 모델과 도면 | 기계도면 치수와 공차 추출 |

공개 데이터 결과를 항공기 제조 도면으로 일반화하려면 추가 검증이 필요함.

## 10. 요약

| 항목 | 내용 |
|---|---|
| 시각 우선 검색 | 문자 추출 성공 여부와 무관하게 모든 그림을 다중 해상도 이미지 임베딩으로 색인 |
| 구조 기반 이해 | 그림 유형별 비생성형 모델로 기호, 연결, 치수, 부품 참조를 좌표와 신뢰도와 함께 구조화 |
| 자원 적응 처리 | 영역 복잡도에 따른 시각 토큰 배정, 차원 단계화, 상위 후보 정밀 재검색 |

목표의 정확한 표현은 "모든 그림을 빠짐없이 색인하고 종류와 복잡도에 맞는 시각 이해 모델로 기술정보의 추출 범위와 검색 정확도를 최대화함"임. 모든 그림의 의미를 완전히 이해한다는 주장은 하지 않음. 연결 관계, 화살표 방향, 시각적 계층의 해석은 생성형 VLM에서도 미해결 과제임.
