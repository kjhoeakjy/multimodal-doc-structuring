# v8: 그림·표·각주에 분산된 정보의 관계와 적용 조건 연결을 위한 데이터 전처리·구조화 방안

작성 2026-10-28. v7 평가를 반영함. 아이디어 방향은 유지하고 사례, 스키마, 관계 연결 방식, 검증 비교 기준을 수정함.

**주제:** 비정형 데이터(표, 이미지 등)를 AI가 효율적으로 이해하고 활용할 수 있도록 하기 위한 데이터 전처리 및 구조화 방안

**핵심 아이디어:** 서로 다른 위치와 형식에 분산된 정보가 무엇을 설명하고 어떤 조건에서 유효한지 연결해 LLM에 전달함.

**포지셔닝:** 새로운 알고리즘이 아닌 산업 기술자료의 해석 오류 가능성을 줄이는 문제 해결 설계. 구조 보존, 출처 추적, 경량 문서 모델 등 기존 기술을 이 목적에 맞게 조합함.

**설계 전제:** 독립 실행 가능한 오픈소스 모델 활용. 제한된 연산 자원을 고려한 효율적 처리. 특정 조직의 시스템이나 자원 상황을 전제하지 않음.

## 0. v7 대비 변경

| v7 | v8 | 사유 |
|---|---|---|
| 그림과 표에 모두 A-17 표기 | 그림에서 부품의 소속 구역 확인, 표에서 구역별 값 확인, 각주에서 조건 확인 | 표와 각주로 답할 수 있어 이미지 처리의 필요성 미증명 |
| 원본 헤더 '온도'를 '허용 온도'로 구조화 | 원본 헤더 '최대 허용 온도'를 그대로 사용 | 원본에 없는 의미 추가 금지 |
| 대상, 값, 조건, 출처 네 묶음 | 대상, 속성·관계, 값, 적용 조건, 출처 다섯 묶음 | 속성이 없으면 최대 허용 온도와 측정 온도 등의 구분 불가 |
| 해석이 필요한 관계는 소형 모델 | 이미지의 객체·구역·라벨은 식별자와 공간적 관계 확인 후 연결 | 그림 정보와 표 정보의 결합 방식 명시 |
| 반복 이미지 처리 감소 주장 | 전처리 비용과 구조화 효과를 구분해 비교 | 일반 RAG도 파싱 결과를 저장해 재사용 가능 |
| 제목과 본문의 '구조·조건 보존' 반복 | 실제 정보(구역, 헤더, 각주) 지칭 | 표현 반복 축소 |

## 1. 문제

기술자료의 정보는 여러 위치와 형식에 분산됨. 부품의 위치는 그림에, 구역별 기준값은 표에, 적용 조건은 각주에 기록되는 경우가 있음. 텍스트 변환 과정에서 세 정보가 분리되면 값을 정확히 추출하더라도 어떤 대상에 어떤 조건으로 적용되는지 알 수 없음.

## 2. 해결 방안

### 2.1 데이터 전처리

**원본 직접 추출.** 텍스트 레이어가 있는 문서와 디지털 표는 파서로 텍스트, 셀, 위치를 추출함.

**선택적 소형 VLM 적용.** 시각적 해석이 필요한 페이지 또는 영역에 소형 VLM을 적용함. 표 구조와 레이아웃 추출에 더해 그림의 객체, 구역, 라벨이 필요한 경우 해당 기능을 지원하는 모델을 선택함. 추출이 불완전한 영역에 한해 재처리하며 검증 전의 추출값은 확정된 사실로 취급하지 않음.

### 2.2 데이터 구조화

**정보 구조.** 대상, 속성·관계, 값, 적용 조건, 출처 다섯 묶음으로 저장함. 단위는 값과 함께 표기하고 문서 버전, 페이지, 좌표는 출처에 포함함.

| 대상 | 속성·관계 | 값 | 적용 조건 | 출처 |
|---|---|---|---|---|
| A-17 | 소속 구역 | ZONE-2 | 없음 | 그림 1 |
| ZONE-2 | 최대 허용 온도 | 80°C | 정상 운전 | 표 1, 각주 |

**관계 연결 방식.** 표의 헤더, 셀, 각주 관계는 문서 구조를 이용해 연결함. 이미지에서 추출한 객체, 구역, 라벨은 식별자와 공간적 관계를 확인해 연결함. 공간적 근접을 근거로 포함 관계를 확정하지 않으며 경계나 연결선이 불명확한 경우 미확정 상태로 원본과 함께 보존함.

**질의 시 입력 구성.** 저장된 관계를 따라 질문에 필요한 값, 조건, 출처를 복원해 LLM에 전달함.

## 3. 사례: 가상 기술자료

**원본 구성**

- 그림 1: 부품 배치도. A-17이 ZONE-2 경계 안에 위치
- 표 1: 구역별 기준

| 구역 | 최대 허용 온도 |
|---|---|
| ZONE-1 | 70°C |
| ZONE-2 | 80°C* |

\* 정상 운전 조건에서 적용

**질문:** A-17의 정상 운전 시 최대 허용 온도는?

**필요한 정보:** 그림 1에서 A-17의 소속 구역(ZONE-2) 확인, 표 1에서 ZONE-2의 값(80°C) 확인, 각주에서 적용 조건(정상 운전) 확인. 세 정보 중 하나라도 누락되면 정확한 답변 불가.

**구조화 결과:** A-17은 ZONE-2에 속함. ZONE-2의 최대 허용 온도는 정상 운전 조건에서 80°C. 출처는 그림 1의 구역 경계, 표 1의 셀, 각주.

## 4. 검증

비교 대상에 불리한 가정을 두지 않음. 모든 방식은 파싱 결과를 저장해 재사용하는 조건으로 비교함.

| 구분 | 비교 | 지표 |
|---|---|---|
| 전처리 | 전체 페이지 VLM 처리와 필요 영역 VLM 처리 | 전처리 GPU 비용 |
| 구조화 | 고정 길이 청킹 검색 결과 입력과 관계·조건 복원 입력 | 관계 연결 정확도, QA 정답률, 질의당 입력 토큰 |

측정 전이므로 수치는 기재하지 않음. 구조화로 정확도가 낮아지는 경우도 기록함.

## 5. 1장 구성

제목: 그림·표·각주에 분산된 정보의 관계와 적용 조건 연결

- 핵심 문제: 그림, 표, 각주에 분산된 정보가 텍스트 변환 과정에서 분리될 가능성
- 데이터 전처리: 원본 파싱 우선, 시각적 해석이 필요한 영역에 소형 VLM 적용
- 데이터 구조화: 대상, 속성·관계, 값, 적용 조건, 출처 연결 후 질문에 필요한 정보로 입력 구성
- 사례: A-17의 소속 구역(그림), ZONE-2 최대 허용 온도(표), 정상 운전 조건(각주)
- 검증: 관계 연결 정확도, QA 정답률, 전처리 GPU 비용, 질의당 입력 토큰

모델명과 저장 형식 세부는 1장에 포함하지 않음. 특정 내부 업무와 시스템은 언급하지 않음.
