# multimodal-doc-structuring

비정형 데이터(표, 이미지, 기술문서)를 AI가 효율적으로 이해하고 활용할 수 있도록 하는 데이터 전처리와 구조화 방안. 폐쇄망과 제한된 연산 자원에서 공개 모델로 운용하는 조건을 전제로 함.

## 현행 구상

[v10 표와 이미지에 분산된 정보의 관계와 적용 조건을 보존하는 전처리 및 구조화 방안](docs/concept/v10-적용-조건-보존-전처리-구조화.md)

- 핵심: 비정형 데이터의 전체 내용을 우선 추출하고 관계가 누락되거나 불확실한 영역에 한해 추가 분석한 뒤, 분산된 정보와 적용 조건을 연결해 LLM이 활용할 수 있도록 구조화함
- 전처리: 전체 기본 추출, 구조화와 관계 점검, 선택적 추가 분석(고해상도 재처리 또는 소형 시각언어모델), 저장
- 구조화: 대상, 속성 또는 관계, 값, 적용 조건, 출처로 저장. 문서 등록 시 1회 처리, 질의 시 조건에 맞는 항목으로 입력 한정
- 전체 그림: [docs/figures](docs/figures/README.md)

## 읽는 순서

1. 현행 구상안 `docs/concept/v10-*.md`
2. 전체 그림 `docs/figures/`
3. 검증 데이터와 결과 `poc/README.md`, `poc/v4/README.md`
4. 근거 `docs/research/`

## 구성

| 경로 | 내용 |
|---|---|
| `docs/concept/` | 현행 구상안. 대체된 버전은 `archive/`에 보존 |
| `docs/figures/` | 구상안 전체 그림과 생성 스크립트 |
| `docs/research/` | 논문 정독 노트, 인용 출처 검증, 구현 후보와 비교군 후보, 제조 문서 풀 선정 |
| `poc/` | 실험 코드. 버전별 목적과 상태는 `poc/README.md` |
| `deck/archive/` | 이전 1장 초안 |

## 작성 규칙

- 공개 저장소. 특정 조직의 내부 시스템, 모델, 인원, 운영 현황 기재 금지. 일반적인 폐쇄망과 공개 모델 환경으로 표현
- 문서는 한국어 문어체. 표와 제목은 명사형 또는 "-함"
- 구상안은 버전별 md로 관리하고 대체된 안은 `archive/`로 이동
- 실측과 합성 데이터 결과는 구분 표기. 통제 실험의 한계 명시
- 생성 데이터, 렌더 이미지, 캐시는 커밋하지 않음(`.gitignore`)
