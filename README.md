# multimodal-doc-structuring

폐쇄망·제한된 GPU 환경에서 공개 가중치 LLM이 비정형 데이터(표·이미지·기술문서)를 효율적으로 이해·활용하도록 하는 전처리·구조화 방안.

## 현행 구상

[v4 전처리·구조화 두 축](docs/concept/v4-전처리-구조화-두-축.md) (확정 대기)

- 전처리: 형식 판별·경로 분기, 이미지 유형별 변환, 정규화, 적재 시점 일괄 처리, 재구성 대조 검증
- 구조화: 자기완결 정보 단위, 계층 보존, 세 가지 표현, 입력 예산 기반 조립

## 구성

| 경로 | 내용 |
|---|---|
| `docs/concept/` | 구상안(현행 v4, 이전 v1~v3) |
| `docs/research/` | 인용 출처 검증 |
| `poc/archive/` | 이전 구상안 PoC(v1 실행 결과 포함, v2 미완성 초안) |
| `deck/archive/` | 이전 1장 초안 |

## 작성 규칙

- 공개 저장소. 특정 조직의 내부 시스템·모델·인원·운영 현황 기재 금지. 일반적인 폐쇄망·공개 가중치 모델 환경으로만 표현.
- 문서는 한국어 문어체. 표·제목은 명사형 또는 "-함".
- 구상안은 `docs/concept/`에 버전별 md로 관리. 대체된 안은 이력으로 보존.
- 실측과 합성 데이터 결과는 구분 표기. 통제 실험의 한계 명시.
- 생성 데이터·렌더 이미지(`data/`, `render/`)는 커밋하지 않음.
