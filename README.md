# multimodal-doc-structuring

폐쇄망·제한된 GPU 환경에서 공개 가중치 LLM이 비정형 데이터(표·이미지·기술문서)를 효율적으로 이해·활용하도록 하는 전처리·구조화 방안.

## 현행 구상

[v9 표와 이미지에 분산된 정보의 관계와 적용 조건을 보존하는 전처리 및 구조화 방안](docs/concept/v9-적용-조건-보존-구조화-차별점.md)

- 핵심 아이디어: 그림, 표, 각주에 나뉘어 기록된 값과 적용 조건을 연결해 저장하고 질문의 조건에 맞는 값과 출처를 LLM에 전달
- 데이터 전처리: 1차 추출로 요소와 위치 확보, 명시적 참조의 연결 확인, 예상 연결이 없는 영역에 한해 소형 시각언어모델(VLM) 재해석
- 데이터 구조화: 대상, 속성 또는 관계, 값, 적용 조건, 출처로 저장. 표는 문서 구조로 연결하고 이미지의 객체와 구역은 식별자와 공간적 관계 확인 후 연결. 불명확한 연결은 미확정
- 사례: 부품 배치도의 소속 구역, 구역별 기준 표의 최대 허용 온도 기준, 각주의 정상 운전 조건(구역 기준을 부품 자체의 기준으로 해석하지 않음)
- 면접 대비 기술 검토: [v5 초안](docs/concept/v5-초안-두-축-재편.md), [논문 정독 노트](docs/research/논문-정독-노트.md)

## 작성 규칙

- 공개 저장소. 특정 조직의 내부 시스템·모델·인원·운영 현황 기재 금지. 일반적인 폐쇄망·공개 가중치 모델 환경으로 표현.
- 문서는 한국어 문어체. 표·제목은 명사형 또는 "-함".
- 구상안은 `docs/concept/`에 버전별 md로 관리. 대체된 안은 이력으로 보존.
- 실측과 합성 데이터 결과는 구분 표기. 통제 실험의 한계 명시.
- 생성 데이터·렌더 이미지(`data/`, `render/`)는 커밋하지 않음.
