# multimodal-doc-structuring

비정형 데이터(표, 이미지, 기술문서)를 AI가 효율적으로 이해하고 활용할 수 있도록 하는 데이터 전처리와 구조화 방안. 폐쇄망과 제한된 연산 자원에서 기존 텍스트 LLM으로 운용하는 조건을 전제로 함.

## 현행 구상

[v1 항공기 기술문서의 구조와 참조 관계 보존을 위한 비정형 데이터 전처리 및 검색 연계](docs/concept/v1-기술문서-구조-참조-관계-보존-전처리-검색.md)

- 과제: PDF, 표, 도면, CAD의 기술정보를 구조화하고 부품, 규격, 문서 사이의 관계를 보존해 기존 텍스트 LLM이 정확하게 활용하도록 함
- 전처리: 원본 우선 직접 추출. OCR, 레이아웃, 표 구조 인식(TableFormer)은 필요한 영역에 한정. STEP 원본 속성 직접 추출
- 구조화: 공통 스키마, 규격과 근거 분리, 근거 관계 테이블, 식별자와 단위 정규화, 개정과 적용 범위 관리
- 검색: 식별자 조회, BM25, 임베딩 검색, 순위 결합, 관계 확장. 조회 수치는 그대로 전달
- 환경: 폐쇄망, CPU 중심 전처리, 기존 텍스트 LLM, 대형 VLM 미사용

## 작성 규칙

- 공개 저장소. 특정 조직의 내부 시스템, 모델, 인원, 운영 현황 기재 금지. 일반적인 폐쇄망과 공개 모델 환경으로 표현
- 문서는 한국어 문어체. 표와 제목은 명사형 또는 "-함"
- 구상안은 버전별 md로 관리하고 대체된 안은 `docs/concept/archive/`로 이동
- 실측과 합성 데이터 결과는 구분 표기. 통제 실험의 한계 명시
- 생성 데이터, 렌더 이미지, 캐시는 커밋하지 않음(`.gitignore`)
