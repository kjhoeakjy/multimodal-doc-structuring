# multimodal-doc-structuring

폐쇄망·제한된 GPU 환경에서 공개 가중치 LLM이 비정형 데이터(표·이미지·기술문서)를 효율적으로 이해·활용하도록 하는 전처리·구조화 방안.

## 현행 구상

[v8 그림·표·각주에 분산된 정보의 관계와 적용 조건 연결을 위한 데이터 전처리·구조화 방안](docs/concept/v8-분산-정보의-관계와-적용조건-연결.md)

- 핵심 아이디어: 서로 다른 위치와 형식에 분산된 정보가 무엇을 설명하고 어떤 조건에서 유효한지 연결해 LLM에 전달
- 데이터 전처리: 원본 직접 추출, 시각적 해석이 필요한 페이지·영역에 소형 VLM, 불완전 영역 재처리
- 데이터 구조화: 대상·속성/관계·값·적용 조건·출처, 표는 문서 구조로 연결, 이미지 객체·구역·라벨은 식별자와 공간적 관계 확인 후 연결, 불명확한 연결은 미확정
- 사례: 그림(A-17의 소속 구역 ZONE-2), 표(ZONE-2 최대 허용 온도 80°C), 각주(정상 운전 조건)
- 면접 대비 기술 검토: [v5 초안](docs/concept/v5-초안-두-축-재편.md), [논문 정독 노트](docs/research/논문-정독-노트.md)

## 작성 규칙

- 공개 저장소. 특정 조직의 내부 시스템·모델·인원·운영 현황 기재 금지. 일반적인 폐쇄망·공개 가중치 모델 환경으로 표현.
- 문서는 한국어 문어체. 표·제목은 명사형 또는 "-함".
- 구상안은 `docs/concept/`에 버전별 md로 관리. 대체된 안은 이력으로 보존.
- 실측과 합성 데이터 결과는 구분 표기. 통제 실험의 한계 명시.
- 생성 데이터·렌더 이미지(`data/`, `render/`)는 커밋하지 않음.
