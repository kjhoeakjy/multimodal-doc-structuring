# multimodal-doc-structuring

비정형 데이터(표, 이미지, 기술문서)를 AI가 효율적으로 이해하고 활용할 수 있도록 하는 데이터 전처리와 구조화 방안. 폐쇄망과 제한된 연산 자원에서 기존 텍스트 LLM으로 운용하는 조건을 전제로 함.

## 현행 구상

[v5 기술 그림의 관계 그래프 기반 구조화 및 LLM 연계](docs/concept/v5-기하-요소-그래프-기반-기술-그림-구조화.md) (세부: [v5-상세](docs/concept/v5-상세.md))

- 문제: 기존 OCR과 RAG는 그림의 문자는 추출하나 연결, 위치, 지시 관계를 잃음
- 해결책: 기술 도면과 도식의 시각 요소를 추출해 요소 간 관계의 그래프로 구조화하고 질문 관련 부분 그래프를 텍스트로 기존 텍스트 LLM에 전달
- 경쟁 포인트: 요소 간 관계를 기존 텍스트 LLM이 활용할 수 있는 공통 구조로 변환
- 초기 범위: 문자, 기호, 연결 관계 복원. 치수와 형상 대응, 차트는 이후 확장. 사진과 렌더링은 이미지 검색에 한정
- 검증: OCR 기반 RAG와 관계 질의 정답률, 처리 시간, GPU 사용량 비교. 관계마다 원본 영역 추적
- 환경: 생성형 VLM 미사용, 기존 텍스트 LLM, 폐쇄망, 제한된 GPU
- 이전 안: `docs/concept/archive/`

## 예시

[공개 참조 P&ID 한 장의 관계 그래프 변환](examples/dexpi-reference-pid/README.md). 선, 곡선, 타원, 문자만으로 장비 5, 계기 4, 밸브와 기호 19, 배관 구간 44개를 추출하고 정답 인접 쌍 27개를 모두 복원함. 질문별 부분 그래프를 텍스트로 직렬화해 기존 텍스트 LLM에 전달하는 형태까지 포함.

## 작성 규칙

- 공개 저장소. 특정 조직의 내부 시스템, 모델, 인원, 운영 현황 기재 금지. 일반적인 폐쇄망과 공개 모델 환경으로 표현
- 문서는 한국어 문어체. 표와 제목은 명사형 또는 "-함"
- 구상안은 버전별 md로 관리하고 대체된 안은 `docs/concept/archive/`로 이동
- 실측과 합성 데이터 결과는 구분 표기. 통제 실험의 한계 명시
- 생성 데이터, 렌더 이미지, 캐시는 커밋하지 않음(`.gitignore`)
