# multimodal-doc-structuring

비정형 데이터(표, 이미지, 기술문서)를 AI가 효율적으로 이해하고 활용할 수 있도록 하는 데이터 전처리와 구조화 방안. 폐쇄망과 제한된 연산 자원에서 기존 텍스트 LLM으로 운용하는 조건을 전제로 함.

## 현행 구상

[v3 복잡한 기술도면의 시각, 기하, 의미 정보 보존을 위한 적응형 전처리 및 검색](docs/concept/v3-기술도면-시각-기하-의미-정보-보존-전처리-검색.md)

- 과제: 기술문서의 모든 그림을 검색 가능하게 색인하고 검증 가능한 기술정보(치수, 규격, 부품, 연결, 적용 조건)를 별도 구조로 추출함
- 전처리: 원본 벡터와 기하 정보 우선. 화소 경로는 도면 전용 OCR, 선과 접점 추적, 관계 모델
- 검색: 계층형 시각 임베딩, 식별자 조회, BM25, 상위 후보 패치 단위 재검색
- 확정: 탐지 점수가 아닌 검증 규칙과 보정 기준. 불확실 시 원본 제시와 보류
- 환경: 생성형 VLM 미사용, 기존 텍스트 LLM, 폐쇄망, 제한된 GPU
- 이전 안: `docs/concept/archive/`

## 구성

| 경로 | 내용 |
|---|---|
| `docs/concept/` | 현행 구상안. 버전별 md로 관리 |
| `archive/이전-구상/` | 이전 구상 과정의 구상안, 그림, 조사 문서, 실험 코드 |

## 작성 규칙

- 공개 저장소. 특정 조직의 내부 시스템, 모델, 인원, 운영 현황 기재 금지. 일반적인 폐쇄망과 공개 모델 환경으로 표현
- 문서는 한국어 문어체. 표와 제목은 명사형 또는 "-함"
- 구상안은 버전별 md로 관리하고 대체된 안은 `docs/concept/archive/`로 이동
- 실측과 합성 데이터 결과는 구분 표기. 통제 실험의 한계 명시
- 생성 데이터, 렌더 이미지, 캐시는 커밋하지 않음(`.gitignore`)
