# 추출 연결 검증 사전 판정

추출한 배관 연결 가운데 틀린 연결을 적은 검토 비용으로 찾을 수 있는지 판정하는 예비 실험. 개발 도면 8개 조건(C01 벡터·200 dpi·스캔, C02, C03, 증류 플랜트 벡터·150 dpi, 증류 실험실)의 추출 그래프에 정답 대조로 정답·오류를 붙이고 검토 순서 점수를 비교함.

```
PYTHONPATH=../../app:../dexpi-reference-pid python feasibility.py   # result.md
```

## 결과 요약(2026-11-02)

| 점수 | 도면 평균 AUC | 오류 재현율@20% |
|---|---|---|
| 무작위 | 0.50 | 0.20 |
| 끝점 간격 | 0.47 | 0.21 |
| 위상·도메인 제약 위반(학습 없음) | 0.64 | 0.23 |
| 로지스틱 회귀(도면 단위 교차 검증) | 0.64 | 0.22 |

- 끝점 간격은 무작위와 같은 수준이라 기하 거리 기준의 검토 순서는 효과가 없음
- 위상·도메인 제약(분기점 차수, 2구 부품 차수 초과, 노즐 수 초과, 막다른 끝)은 AUC 0.64로 신호가 있으나 검토 예산 20%에서 이득이 작음
- 래스터 조건은 연결의 65~98%가 오류라 검토 순서보다 추출 자체가 문제임. 검증은 정밀도를 올리는 수단이며 누락된 연결(재현율)은 회복하지 못함
- 정답·오류 판정에는 노드 대응 실패(병합 등)에서 오는 잡음이 섞여 있음
- 다음 판정 항목: 같은 도면을 해상도·이진화 임계값을 바꿔 여러 번 추출했을 때의 연결 일치도, 원본 영역 재분석 점수
