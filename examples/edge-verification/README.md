# 추출 연결 검증 사전 판정

추출한 배관 연결 가운데 틀린 연결을 적은 검토 비용으로 찾을 수 있는지 판정하는 예비 실험. 개발 도면 8개 조건(C01 벡터·200 dpi·스캔, C02, C03, 증류 플랜트 벡터·150 dpi, 증류 실험실)의 추출 그래프에 정답 대조로 정답·오류를 붙이고 검토 순서 점수를 비교함.

```
PYTHONPATH=../../app:../dexpi-reference-pid python feasibility.py   # result.md
```

## 결과 요약(2026-11-02)

| 검토 순서 점수 | 도면 평균 AUC |
|---|---|
| 무작위 | 0.50 |
| 끝점 간격 | 0.47 |
| 위상·도메인 제약 위반(학습 없음) | 0.64 |
| 다중 추출 불일치(`consistency.py`, 학습 없음) | 0.67 |
| 제약 위반 + 불일치 | 0.67 |
| 로지스틱 회귀(도면 단위 교차 검증) | 0.68 |
| 선 경로의 잉크 지지율(래스터 3조건, 별도 측정) | 0.47~0.64 |

- 판정 기준(AUC 0.75)에 미달. 도면별로는 C03(0.90), 증류 플랜트 150 dpi(불일치 0.87), C01 200 dpi(제약+불일치 0.77)에서 높고 증류 플랜트 벡터(0.52)·증류 실험실(0.35~0.64)에서 낮음
- 끝점 간격과 잉크 지지율이 무작위 수준임. 틀린 연결도 실제로 그려진 선을 따라가므로 없는 선을 만든 오류가 아니라 요소·분기점 해석의 오류임
- 래스터 C01의 틀린 연결 35개 중 24개가 연결 둘인 분기점(꺾임·분할 지점)을 지남. 이 분기점을 축약하면 정밀도가 0.35에서 0.56으로 오름(`labelled_pairs(contract=True)`). 정밀도 저하의 상당 부분은 위상 정규화가 없는 데서 옴
- 래스터 조건은 연결의 65~98%가 오류라 검토 예산 대비 오류 재현율은 지표로 맞지 않음. AUC와 검토 구간 정밀도로 봄
- 정답·오류 판정에는 노드 대응 실패(병합 등)에서 오는 잡음이 섞여 있음
