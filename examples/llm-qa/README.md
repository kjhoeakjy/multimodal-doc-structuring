# 질의응답 정답률 실험

구조화 결과가 텍스트 전용 LLM의 답에 얼마나 도움이 되는지 잰다. 같은 문서에 대해 세 가지 입력 조건으로 같은 질문을 하고 정답률을 비교함.

| 조건 | 입력 | 뜻 |
|---|---|---|
| `ocr` | 문자 인식 결과(벡터는 SVG 문자)를 읽는 순서로 이어 붙인 텍스트 | 구조화 없는 기준선 |
| `full` | 전체 직렬화(`graph.txt`·`page.txt`: 요소·연결·표·문단·관계) | 문서 한 장을 통째로 투입 |
| `retrieved` | 질문 태그 기준 2단계 부분 그래프와 질문어가 겹치는 줄(표 머리글 포함) | 검색 후 투입(RAG) |

## 자료와 정답

| 자료 | 문항 | 정답 출처 |
|---|---|---|
| DEXPI C01 P&ID: 벡터, 200 dpi 래스터, 스캔 열화 | 43 × 3 | DEXPI XML(연결·노즐 수·노즐 호칭 지름·라인 속성·계기 기능 문자) |
| DEXPI C02·C03 P&ID 벡터 | 12 | DEXPI XML |
| 합성 보고서(영문 PDF 글자 층·150 dpi 스캔), 한글 보고서, 한글 표·본문 스캔 | 35 | 생성 스크립트의 값 |
| 합성 기계 도면(벡터·래스터) | 20 | 생성 스크립트의 값 |
| FAA AC 43.13-1B 토크 표(원본·스캔), 볼트 표, 본문 2단 쪽 | 44 | 원문 대조 값 |

DEXPI 플랜트·실험실 도면(DP·DL)은 그림과 XML 모두에 문자 라벨이 없어 태그 기준 질문을 만들 수 없으므로 제외함.

연결 질문은 "장비 X에서 배관을 따라 다른 장비를 거치지 않고 바로 도달하는 장비 태그"이며 정답은 XML 연결 정보에서 이름 없는 부품(밸브 등)을 지나 탐색해 만든 집합임. 채점은 단일 답은 정규화 후 포함 여부, 집합 답은 응답에서 뽑은 태그 집합의 완전 일치.

## 실행

```
python prepare_docs.py          # C02·C03 벡터 도면 처리(표본 결과는 examples/sample-inputs/output 사용)
python make_questions.py        # questions.json
python contexts.py              # contexts.json(세 조건 문맥)
python run_qa.py --backend api --model <모델 id> --label <결과 이름>   # OpenAI 호환 API, 환경 변수 LLM_API_BASE·LLM_API_KEY
python run_qa.py --backend ollama --model <모델 이름>        # 공개 가중치 모델, 로컬 Ollama
bash run_open_models.sh [모델 ...]  # 공개 가중치 비교군(8B·7B·14B급) 일괄 실행, 결과 이름 open-<규모>-<연월>
python analyze.py <결과 이름>   # results/<결과 이름>-analysis.md: 신뢰구간, 조건 간 대응 비교, 종류별 정답률, 오답 유형
```

결과는 `results/<결과 이름>.jsonl`(문항·조건별 응답)과 `results/<결과 이름>.md`(자료별·질문 종류별 정답률, 입력 길이, 응답 시간). 중단 후 다시 실행하면 남은 문항만 호출함. 결과 이름에는 공급사·모델명을 쓰지 않고 규모와 시점만 적음.

3차 분석(`results/api-small-2026-10-v3-analysis.md`, 부트스트랩 2,000회):

| 조건 | 정답률 | 95% 구간 | 평균 입력 길이(자) |
|---|---|---|---|
| ocr | 40.8% | [34.6, 47.1] | 1,438 |
| full | 55.8% | [49.6, 62.1] | 9,188 |
| retrieved | 51.7% | [45.8, 57.9] | 1,625 |

같은 문항의 대응 비교에서 full은 ocr보다 53문항을 더 맞추고 17문항을 놓침(차이의 95% 구간 [+8.3, +21.7]%p). full과 retrieved의 차이는 [-8.3, 0.0]%p로 구간이 0에 닿음. 질문 종류별로는 관계 질문(연결·개수·노즐·라인·계기)에서 full이 ocr보다 25~40%p 높고, 표·치수·그림 질문은 ocr이 같거나 높음. 오답의 대부분은 '자료에 없음'(ocr 109, full 72)이며 그중 51건은 래스터 P&ID임.

해석:
- 관계 그래프 직렬화의 효과는 벡터 P&ID에서 분명함(16% → 93%). 연결 질문은 모델이 배관·분기점을 여러 단계 따라가지 못해 7%였고, 구조화 단계에서 장비 간 도달을 미리 계산해 넣자 C01 벡터에서 5/5가 됨.
- 표·본문 쪽은 문자 인식 결과만으로 70~100%라 구조화 이득이 없음. 직렬화의 좌표·관계 줄이 오히려 소형 모델을 방해하는 경우(FAA 토크 표 82% → 71%)가 있음.
- 래스터 P&ID는 추출 품질(정답 인접 쌍 11/25)이 상한이 되어 20% 안팎. C02·C03은 장비 태그 문자가 틀·표 제거 단계에서 빠져 답할 수 없음.
- 부분 그래프 조건은 입력 길이가 전체 직렬화의 18%(1,624자 대 9,188자)이면서 정답률은 3%p 차이.
