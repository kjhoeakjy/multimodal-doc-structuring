# PoC v5 구역별 점검 주기(합성)

그림, 표, 각주가 모두 있어야 답할 수 있는 정비 계획 문서를 합성해 구상안의 처리 흐름을 검증함. `poc/v6`의 풀 3으로 사용함.

## 합성 문서

- 영문 1쪽 문서 12건. 구역 위치도(구역 3개, 부품 표지와 라벨, 일부 라벨은 구역 경계선과 겹침), 구역별 점검 주기 표(구역의 약 2/3은 조건별 두 값), 운용 환경 각주
- 형태: 디지털 PDF(텍스트 레이어, 벡터 도형), 스캔본(150dpi, 기울기, 흐림, 잡음, JPEG 압축, 텍스트 레이어 없음)
- 정답: 부품별 소속 구역, 구역별 값과 조건(`data/truth.json`, 생성 시 자동 기록)
- 질문 44개: 조건 지정, 조건 미지정, 단일 기준, 기록 없는 조건

## 파일

| 파일 | 내용 |
|---|---|
| `gen.py` | 합성 문서와 정답, 질문 생성 |
| `extract.py` | 1차 추출(디지털은 텍스트 레이어와 벡터 객체, 스캔은 EasyOCR과 윤곽선 분석), 관계 점검(표지와 라벨, 각주 기호와 각주 문장, 표와 그림의 구역 대응), 연결 누락 영역 재해석, 구조화 |
| `vlm.py` | Granite-Docling 258M 영역 재해석. 입력 크기 512 상한, 생성 길이 상한 |
| `qa.py`, `run_qa.py` | 질의응답 비교(A 고정 분할, C 제안 등) |
| `run_extract.py` | 전 문서 추출과 연결 정확도 기록 |
| `baselines.py`, `e2e.py` | 비교 방식(Docling 기본, Granite-Docling 전체 페이지, Granite Vision 직접 입력) |

## 결과

| 항목 | 결과 |
|---|---|
| 디지털 연결 정확도 | 부품과 구역 87/87, 값 61/61, 값과 조건 61/61. 연결 누락 0건, VLM 호출 0회, 문서당 1초 미만 |
| 스캔 1차 추출 | EasyOCR 쪽당 약 17초(CPU). 각주 기호 미인식, 경계선과 겹친 라벨 판독 실패 |
| 영역 재해석 | 라벨 영역 1개 약 6초에 정확히 판독. 각주 문장 재해석에서 문서에 없는 문장 생성 사례 확인 후 검증 단계 추가 |

스캔본 전체와 질의응답 비교 결과는 실행 완료 후 기재함.
