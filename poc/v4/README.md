# PoC v4 계획 (v8 구상안 기준, 착수 전)

목적: v8의 사례(부품 배치도·구역별 기준 표·각주의 연결)를 합성 기술문서로 재현하고 전처리 비교와 구조화 비교의 지표 4개를 측정함. 1장에는 사례 1건과 측정치를 표시함.

## 합성 문서

- 문서 1건 = 범위 조항 + 부품 배치도(구역 경계와 부품 라벨) + 구역별 기준 표(각주 표시 `*`) + 각주("정상 운전 조건에서 적용", "비상 시 60초 이내") + 주기.
- 부품의 소속 구역은 그림에서, 구역별 값은 표에서, 적용 조건은 각주에서 확인됨. 세 정보 중 하나라도 빠지면 정답 불가.
- 구역 경계 근처에 배치된 부품을 일부 포함해 공간적 근접과 포함 관계의 차이를 측정함.
- 절반은 스캔본(잡음·압축, 텍스트 레이어 없음). 생성기는 poc/v3/gen.py를 확장(구역 경계, 부품 라벨, 각주 조건).
- 정답: 대상·속성/관계·값·단위·적용 조건·출처(표 셀 좌표, 그림 구역 좌표, 각주 번호).

## 질의

| 유형 | 예 | 정답 판정 |
|---|---|---|
| 값 조회 | 2구역의 최대 허용 온도 | 값·단위 일치 |
| 조건 포함 조회 | 2구역의 최대 허용 온도와 적용 조건 | 값과 조건 모두 일치 |
| 그림 연결 | A-17이 설치된 구역에 적용되는 정상 운전 시 최대 허용 온도 기준 | 소속 구역·값·조건 모두 일치 |
| 설명 | 비상 한계의 지속 가능 시간 | 각주 문구 일치 |

## 비교 구성

모든 방식은 파싱 결과를 저장해 재사용함. 비교 대상에 불리한 가정을 두지 않음.

| 구분 | 비교 | 실행 위치 |
|---|---|---|
| 전처리 | 전체 페이지 VLM 처리와 시각적 해석이 필요한 영역 VLM 처리(Granite-Docling) | 노트북(CPU, 가중치 보유) |
| 구조화 | 고정 길이로 분할한 텍스트의 검색 결과 입력(tesseract OCR 또는 텍스트 레이어)과 대상·속성/관계·값·적용 조건·출처 복원 입력 | 파싱은 컨테이너, VLM은 노트북 |

동일 LLM(로컬 소형 모델, 노트북 CPU 또는 판정 규칙), 동일 질의, 동일 문서.

## 주의

- 합성 데이터 결과임을 1장에 명시.
- 고정 길이 분할 방식이 각주와 구역을 올바르게 읽는 경우도 그대로 기록. 틀린다고 전제하지 않음.
- 구조화로 정확도가 낮아지는 유형이 있으면 기록.
- 생성 데이터·렌더 이미지는 커밋하지 않음(.gitignore).
